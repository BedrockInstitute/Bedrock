## 2. The principle as a type

The candidate principle is the three-case transfinite induction on S.

```agda
module OrdFrame
  (P : S → Type (ℓ-suc ℓ))
  (z : P ∅)
  (s : (δ : S) → IsOrd δ → P δ → P (sucV δ))
  (l : (λ : S) → IsOrd λ → ⟨ isLimit λ ⟩
     → ((δ : S) → ⟨ δ ∈ˢ λ ⟩ → P δ) → P λ)
  where
  frame : (β : S) → IsOrd β → P β
```

What holds at zero: z : P ∅. What transfers at successors: s, from the
predecessor. What carries at limits: l, from the raw membership sequence
below λ. The proof of frame is ∈-induction plus ord-case.

The principle is TRUE. Q's qstep (Bridge:1055-1067) is a proof of it at
one P, with the three clause names hard-wired. Extracting the module is
mechanical: about 17 code lines. The tree holds the case machinery:
ord-case and the isLimit facts at Bridge:52, isLimit-not-zero and
isLimit-not-succ at OrdArith:168-175.
