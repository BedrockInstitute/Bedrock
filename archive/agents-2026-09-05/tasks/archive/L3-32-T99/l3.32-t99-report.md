## 3. The instantiations

Both one-line instantiations sit in `/tmp/t99/ProbeT99ChaseInst.lagda.md`,
applying the generic chase at `E := λ n → ⟪ # n ⟫` with the delivered count
from `FiniteBase` (`toFin`, `toFin-inj`, `fromFin`, `fromFin-inj`) and the
existing embeddings (`FiniteBase.numeral-into-α`/`-inj`, `CoreAtω.
numeral-into-ω`/`-inj`), no postulate, no hole, no termination pragma:

```agda
no-inj-finite′ : (α : S) (oα : IsOrd α) (ω∈α : ⟨ ω ∈ˢ α ⟩)
               → (n : ℕ) → (f : ⟪ α ⟫ → ⟪ # n ⟫ × ⟪ # n ⟫)
               → ((x y : ⟪ α ⟫) → f x ≡ f y → x ≡ y) → Empty.⊥
no-inj-finite′ α oα ω∈α n f finj =
  AbstractChase.NoInj.no-inj
    (λ n → ⟪ # n ⟫)
    SL.FiniteBase.toFin SL.FiniteBase.toFin-inj
    SL.FiniteBase.fromFin SL.FiniteBase.fromFin-inj
    (⟪ α ⟫)
    (SL.FiniteBase.numeral-into-α α oα ω∈α)
    (SL.FiniteBase.numeral-into-α-inj α oα ω∈α)
    n f finj
```

and the mirror at `A := ⟪ ω ⟫` with `CoreAtω`'s embeddings. The concrete
numeral `⟪ # n ⟫` appears only in the instantiations' exported statements,
not in the generic chase's elaboration: the body was checked once against
neutral `E`, and each instantiation is a one-line module application whose
conversion checks are definitionally trivial.

## 4. D-10 check on [T88]'s telescope

The dispatch's reading is **confirmed directly from the source**.
`/tmp/t88/ProbeT88SquareLaw2a.lagda.md:135-140`:

```agda
  module NoInj (A : Type ℓ) (into : (m : ℕ) → ⟪ # m ⟫ → A)
               (into-inj : (m : ℕ) (i₁ i₂ : ⟪ # m ⟫)
                         → into m i₁ ≡ into m i₂ → i₁ ≡ i₂) where

    no-inj : (n : ℕ) → (f : A → ⟪ # n ⟫ × ⟪ # n ⟫)
           → ((x y : A) → f x ≡ f y → x ≡ y) → Empty.⊥
```

and the instantiation at :195-197 passes `⟪ α ⟫` as the carrier. The same
telescope is in probe 2 (`/tmp/t88/ProbeT88SquareLaw2.lagda.md:135-139`).
So [T88] abstracted the TARGET (the carrier `A` for `⟪ α ⟫`/`⟪ ω ⟫`) while
leaving the SOURCE presentation `⟪ # m ⟫` in the `into`/`into-inj` types and
`⟪ # n ⟫` in the chase statement, and the elaboration walled. This dispatch
abstracts the source instead (`E m` for `⟪ # m ⟫` everywhere), which is the
untried direction, and it is green. The premise the whole probe rests on is
true, and the design was the right one.
