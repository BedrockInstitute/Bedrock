# The arity-one code set at the next block

<!--en-->
The successor step consumes one set: the codes of the unary formulas over a
carrier, asked to be a member of the next block. This chapter builds that set
and delivers everything about it that is free, and it names the one object
that is not. The covering half is free: the set is a small family indexed by
the external syntax, so membership in it is the index itself, in both
directions. The containment half is free: at a limit level holding the
carrier, every code is a member, one application of the pairing operation per
pair layer, and that is the limit fact the corrected target spends. What is
not free is the member half: the set itself enters the level above through one
arm at one stage, which asks for a rud value equal to it, and the only
delivered machine that manufactures such a value from a description is the
satisfaction engine. The description is therefore the chapter's residue,
stated once, typed, and connected to the consumer's obligation: from a formula
of the object language over a level below the block whose definable set is the
code set, the block membership follows outright.
<!--zh-->
后继步消费一个集合：某载体之上诸一元公式的码，被要求成为下一个块的成员。本章造出这个集合，把关于它的一切免费部分交付，并点名那件不免费的对象。覆盖的那一半是免费的：该集合是以外部语法为索引的小族，故属于它本身就是那个索引，两个方向皆然。包含的那一半是免费的：在持有载体的极限层处，每条码都是成员，每层对施用一次配对运算，而这正是修正后的目标所花费的那条极限事实。不免费的是隶属的那一半：集合自身经某个阶段处的一臂进入其上的那一层，这索取一个与它相等的 rud 值，而已交付的机器里唯一能从描述造出这种值的是满足集引擎。故描述就是本章的残留，一次陈述、具名、定型，并接到消费方的义务上：从块下方某层之上的一条对象语言公式，其可定义集恰是码集，块的隶属随即直接得出。
<!--/-->

## The arity-one code family
<!--zh-->
## 一元码族
<!--/-->

<!--en-->
The carrier is a set, and the alphabet of a unary formula over it is the type
of its members. A formula becomes a formula over the hierarchy by naming each
member, and the delivered coding applies. The family is the covering set of
the successor step: one set per arity in the incumbent, here only the arity
the consumer uses, sealed where it is built so that no later type mentioning
it drags the presentation machinery into conversion. Membership in a
`sett`{.Agda} is definitionally the truncated fiber, so the two directions are
the index itself; the seal keeps the equations, and the in-direction and the
two-way spec sit outside it.
<!--zh-->
载体是一个集合，而它之上的一元公式的字母表就是其诸成员的类型。一条公式经点名每个成员而成为层级之上的一条公式，交付好的编码随即适用。这个族就是后继步的覆盖集：在既有章节里每个元数一个集合，此处只有消费方所用的那个元数，在诞生处封印，好让此后任何提到它的类型都不把呈现机器拖进转换。属于一个 `sett`{.Agda} 定义性地就是截断纤维，故两个方向就是索引本身；封内只留等式，而进向与双向规格住在封外。
<!--/-->

```agda
module CodesOne (C : S) where

  ι : ⟪ C ⟫ → S
  ι = ⟪ C ⟫↪

  codeTm : ∀ {n} → Term ⟪ C ⟫ n → S
  codeTm t = VCode.⌜ mapTm ι t ⌝ᵗ

  code : ∀ {n} → Formula ⟪ C ⟫ n → S
  code φ = VCode.⌜ mapFo ι φ ⌝

  IsCode : S → Ω
  IsCode x = ∥ Σ[ φ ∈ Formula ⟪ C ⟫ 1 ] (code φ ≡ x) ∥₁ , squash₁

  opaque
    codeSet : S
    codeSet = sett (Formula ⟪ C ⟫ 1) code

    code∈codeSet : (φ : Formula ⟪ C ⟫ 1) → ⟨ code φ ∈ˢ codeSet ⟩
    code∈codeSet φ = ∣ φ , refl ∣₁

    codeSet-out : (x : S) → ⟨ x ∈ˢ codeSet ⟩ → ⟨ IsCode x ⟩
    codeSet-out x h = h

  codeSet-in : (x : S) → ⟨ IsCode x ⟩ → ⟨ x ∈ˢ codeSet ⟩
  codeSet-in x = PT.rec (snd (x ∈ˢ codeSet))
    (λ { (φ , q) → subst (λ w → ⟨ w ∈ˢ codeSet ⟩) q (code∈codeSet φ) })

  codeSet-spec : (x : S) → (x ∈ˢ codeSet) ≡ IsCode x
  codeSet-spec x = ⇔toPath (codeSet-out x) (codeSet-in x)
```

## Numerals and pairs inside a level
<!--zh-->
## 层内的数码与对
<!--/-->

<!--en-->
A limit level is closed under the sixteen operations, and that is all the
arithmetic a code needs. The Kuratowski pair is the ninth operation outright,
the empty set is the difference of any member with itself, the singleton is
the unordered pair of a set with itself, and the successor is three operations
deep, unioned. Numerals follow by induction, and the induction needs one
member of the level to start the empty set from. The three equations are
stated at a variable argument and proved once, so no concrete level is ever
handed to conversion.
<!--zh-->
极限层对十六个运算封闭，而这就是一个码所需的全部算术。Kuratowski 对直接就是第九个运算，空集是任何成员与自身的差，单点集是一个集合与自身的无序对，而后继深三层、再取并。数码随之由归纳而来，而该归纳需要该层的一个成员，好据以起出空集。三条等式在变元实参上陈述、一次证完，故任何具体的层都不会被交给转换检查。
<!--/-->

```agda
private
  ext-⊆ : {u v : S} → ((x : S) → ⟨ x ∈ˢ u ⟩ → ⟨ x ∈ˢ v ⟩)
        → ((x : S) → ⟨ x ∈ˢ v ⟩ → ⟨ x ∈ˢ u ⟩) → u ≡ v
  ext-⊆ sub sup = extensionalV (λ x → ⇔toPath (sub x) (sup x))

empty-rud : (a : S) → Fof f1 a a ≡ ∅
empty-rud a = ext-⊆ sub sup
  where
  sub : (x : S) → ⟨ x ∈ˢ Fof f1 a a ⟩ → ⟨ x ∈ˢ ∅ ⟩
  sub x h = Empty.rec (both .snd (both .fst))
    where
    both : ⟨ (x ∈ˢ a) ⊓ (¬ (x ∈ˢ a)) ⟩
    both = F1-spec a a x .fst
      (subst (λ w → ⟨ x ∈ˢ w ⟩) (Fof-f1 a a) h)
  sup : (x : S) → ⟨ x ∈ˢ ∅ ⟩ → ⟨ x ∈ˢ Fof f1 a a ⟩
  sup x h = Empty.rec (∅-empty x (∈∈ₛ {a = x} {b = ∅} .fst h))

singleton-rud : (x : S) → Fof f0 x x ≡ ⁅ x ⁆s
singleton-rud x = Fof-f0 x x ∙ sym (singl≡pair x)

sucV-rud : (x : S) → Fof f5 (Fof f0 x (Fof f0 x x)) x ≡ sucV x
sucV-rud x = Fof-f5 (Fof f0 x (Fof f0 x x)) x
  ∙ cong ⋃_ (Fof-f0 x (Fof f0 x x)
             ∙ cong (λ w → ⁅ x , w ⁆) (singleton-rud x))

module InLevel (γ : S) (limγ : ⟨ isLimit γ ⟩) where

  InJ : S → Type (ℓ-suc ℓ)
  InJ x = ⟨ x ∈ˢ Sset γ ⟩

  pr∈J : (a b : S) → InJ a → InJ b → InJ (pr a b)
  pr∈J a b ha hb = subst (λ w → ⟨ w ∈ˢ Sset γ ⟩) (Fof-f9 a b)
    (Jset-rud γ limγ f9 a b ha hb)

  ∅∈J : (a : S) → InJ a → InJ ∅
  ∅∈J a ha = subst (λ w → ⟨ w ∈ˢ Sset γ ⟩) (empty-rud a)
    (Jset-rud γ limγ f1 a a ha ha)

  sucV∈J : (x : S) → InJ x → InJ (sucV x)
  sucV∈J x hx = subst (λ w → ⟨ w ∈ˢ Sset γ ⟩) (sucV-rud x)
    (Jset-rud γ limγ f5 (Fof f0 x (Fof f0 x x)) x
      (Jset-rud γ limγ f0 x (Fof f0 x x) hx
        (Jset-rud γ limγ f0 x x hx hx))
      hx)

  numeral∈J : (a : S) → InJ a → (k : ℕ) → InJ (# k)
  numeral∈J a ha zero    = ∅∈J a ha
  numeral∈J a ha (suc k) = sucV∈J (# k) (numeral∈J a ha k)
```

## Every code is a member
<!--zh-->
## 每个码都是成员
<!--/-->

<!--en-->
With the carrier a member of the level, its members are members too, since a
level is transitive, and that is the only thing the constants of a formula
need. A tag is a pair of a numeral with a payload, so one lemma covers all
twelve tags, and the induction over the formula is then twelve applications of
it, mirroring the code function's own clauses one for one. The induction is
uniform in the arity, because a quantifier's subformula lives one arity up and
the containment of an arity-one code therefore reads codes at every arity.
The consequence is the containment half: every member of the code set is a
member of any limit level holding the carrier.
<!--zh-->
载体既是该层的成员，它的诸成员也就是成员，因为层是传递的，而这正是一条公式的诸常量所需的全部。标签是数码与载荷所成的对，故一条引理覆盖全部十二个标签，而沿公式的归纳随即是它的十二次施用，与码函数自己的诸子句一一对应。归纳在元数上一致，因为量词的子公式住在高一级的元数上，而一条一元码的包含因此要在每个元数上读码。推论就是包含的那一半：码集的每个成员都是任何持有该载体的极限层的成员。
<!--/-->

```agda
module Carrier (γ : S) (limγ : ⟨ isLimit γ ⟩)
               (C : S) (C∈ : ⟨ C ∈ˢ Sset γ ⟩) where

  open CodesOne C
  open InLevel γ limγ

  member∈J : (m : ⟪ C ⟫) → InJ (ι m)
  member∈J m = Sset-trans γ {x = C} {y = ι m}
    (∈∈ₛ {a = ι m} {b = C} .snd (∈ₛ⟪ C ⟫↪ m)) C∈

  numeralJ : (k : ℕ) → InJ (# k)
  numeralJ = numeral∈J C C∈

  mkTag∈J : (k : ℕ) (x : S) → InJ x → InJ (VCode.mkTag k x)
  mkTag∈J k x hx = pr∈J (# k) x (numeralJ k) hx

  codeTm∈J : ∀ {n} (t : Term ⟪ C ⟫ n) → InJ (codeTm t)
  codeTm∈J (con m) = mkTag∈J 0 (ι m) (member∈J m)
  codeTm∈J (var i) = mkTag∈J 1 (# (toℕ i)) (numeralJ (toℕ i))

  code∈J : ∀ {n} (φ : Formula ⟪ C ⟫ n) → InJ (code φ)
  code∈J (t ∈̇ u) = mkTag∈J 0 (pr (codeTm t) (codeTm u))
    (pr∈J (codeTm t) (codeTm u) (codeTm∈J t) (codeTm∈J u))
  code∈J (t ≐ u) = mkTag∈J 1 (pr (codeTm t) (codeTm u))
    (pr∈J (codeTm t) (codeTm u) (codeTm∈J t) (codeTm∈J u))
  code∈J (φ ∧̇ ψ) = mkTag∈J 2 (pr (code φ) (code ψ))
    (pr∈J (code φ) (code ψ) (code∈J φ) (code∈J ψ))
  code∈J (φ ∨̇ ψ) = mkTag∈J 3 (pr (code φ) (code ψ))
    (pr∈J (code φ) (code ψ) (code∈J φ) (code∈J ψ))
  code∈J (φ ⇒̇ ψ) = mkTag∈J 4 (pr (code φ) (code ψ))
    (pr∈J (code φ) (code ψ) (code∈J φ) (code∈J ψ))
  code∈J (¬̇ φ)    = mkTag∈J 5 (code φ) (code∈J φ)
  code∈J ⊤̇        = mkTag∈J 6 (# 0) (numeralJ 0)
  code∈J ⊥̇        = mkTag∈J 7 (# 0) (numeralJ 0)
  code∈J (∃̇ φ)    = mkTag∈J 8 (code φ) (code∈J φ)
  code∈J (∀̇ φ)    = mkTag∈J 9 (code φ) (code∈J φ)
  code∈J (∀̇∈ t φ) = mkTag∈J 10 (pr (codeTm t) (code φ))
    (pr∈J (codeTm t) (code φ) (codeTm∈J t) (code∈J φ))
  code∈J (∃̇∈ t φ) = mkTag∈J 11 (pr (codeTm t) (code φ))
    (pr∈J (codeTm t) (code φ) (codeTm∈J t) (code∈J φ))

  codeSet⊆J : (x : S) → ⟨ x ∈ˢ codeSet ⟩ → InJ x
  codeSet⊆J x h = PT.rec (snd (x ∈ˢ Sset γ))
    (λ { (φ , q) → subst (λ w → ⟨ w ∈ˢ Sset γ ⟩) q (code∈J φ) })
    (codeSet-out x h)
```

## The set itself, and what it would take
<!--zh-->
## 集合自身，以及它要什么
<!--/-->

<!--en-->
The containment half does not give the member half. Membership in the block
factors through one arm at one stage, so it asks for a rud value equal to the
code set, and exactly one delivered machine manufactures such a value out of a
description: the satisfaction engine, read at the pair of levels the successor
step actually uses. The inner level is the limit holding the carrier, which
the corrected target provides, and the outer level is the next block, which is
a limit by construction of the extension and holds the inner one by one
membership step. The residue is stated for an arbitrary target rather than
for the code set, since nothing about the target is used. The entry point is
written so that a discharge never has to produce an equation between sets at a
concrete level: a formula over some level below the block whose definable set
is the target is enough.
<!--zh-->
包含的那一半给不出隶属的那一半。块内的隶属要经某个阶段处的一臂分解，故它索取一个等于码集的 rud 值，而已交付的机器里恰有一台能从描述造出这种值：满足集引擎，在后继步实际所用的那一对层处读出。内层是持有载体的那个极限，由修正后的目标提供；外层是下一个块，按延拓的构造是极限，并经一步隶属持有内层。残留对任意目标陈述、而非只对码集，因为目标自身的任何东西都用不上。入口写成这样：兑付方永远不必在具体层处造出集合之间的等式，只要块下方某层之上的一条公式，其可定义集就是目标。
<!--/-->

```agda
module AtBlock (δ : S) (ordδ : IsOrd δ) (limδ : ⟨ isLimit δ ⟩)
               (C : S) (C∈δ : ⟨ C ∈ˢ Sset δ ⟩) where

  γ : S
  γ = +ω δ

  limγ : ⟨ isLimit γ ⟩
  limγ = +ω-limit δ ordδ

  δ∈γ : ⟨ δ ∈ˢ γ ⟩
  δ∈γ = +ω-mem δ

  module CR = Carrier δ limδ C C∈δ
  module CO = CodesOne C

  codeSet⊆δ : (x : S) → ⟨ x ∈ˢ CO.codeSet ⟩ → ⟨ x ∈ˢ Sset δ ⟩
  codeSet⊆δ = CR.codeSet⊆J

  defSet∈J : (β : S) → ⟨ β ∈ˢ γ ⟩ → (Φ : Formula ⟪ Sset β ⟫ 1)
           → ⟨ DefOf.defSet (Sset β) Φ ∈ˢ Sset γ ⟩
  defSet∈J β β∈γ = SD.defSet-InJ
    where
    module SD = Sat (Sset β)
      (λ x y x∈y y∈W → Sset-trans β {x = y} {y = x} x∈y y∈W)
      (λ x → ⟨ x ∈ˢ Sset γ ⟩)
      (λ a b hb a∈b → Sset-trans γ {x = b} {y = a} a∈b hb)
      (Jset-rud γ limγ)
      (Sset-mem {α = γ} {β = β} β∈γ)

  Description : S → Type (ℓ-suc ℓ)
  Description y =
    ∥ Σ[ β ∈ S ] ( ⟨ β ∈ˢ γ ⟩
      × (Σ[ Φ ∈ Formula ⟪ Sset β ⟫ 1 ] (DefOf.defSet (Sset β) Φ ≡ y)) ) ∥₁

  described∈J : (y : S) → Description y → ⟨ y ∈ˢ Sset γ ⟩
  described∈J y = PT.rec (snd (y ∈ˢ Sset γ)) go
    where
    go : Σ[ β ∈ S ] ( ⟨ β ∈ˢ γ ⟩
         × (Σ[ Φ ∈ Formula ⟪ Sset β ⟫ 1 ] (DefOf.defSet (Sset β) Φ ≡ y)) )
       → ⟨ y ∈ˢ Sset γ ⟩
    go (β , β∈γ , Φ , q) = subst (λ w → ⟨ w ∈ˢ Sset γ ⟩) q (defSet∈J β β∈γ Φ)

  codeSet∈block : Description CO.codeSet → ⟨ CO.codeSet ∈ˢ Sset (+ω δ) ⟩
  codeSet∈block = described∈J CO.codeSet
```

## Recap
<!--zh-->
## 小结
<!--/-->

<!--en-->
The codes of the unary formulas over a carrier form one set (`codeSet`{.Agda}),
sealed at birth, with membership characterized in both directions
(`code∈codeSet`{.Agda}, `codeSet-out`{.Agda}, `codeSet-in`{.Agda},
`codeSet-spec`{.Agda}), which is the covering half the successor step consumes.
Every code is a member of any limit level holding the carrier (`code∈J`{.Agda}),
so the code set is a subset of that level (`codeSet⊆J`{.Agda}). The set's own
membership at the next block is reduced, with no loss, to the satisfaction
engine and one named residue: a formula over a level below the block whose
definable set is the code set (`Description`{.Agda}, `codeSet∈block`{.Agda}).
The discharge of that residue is the object-language code predicate, which is
the incumbent's remaining content and is not rebuilt here.
<!--zh-->
载体之上诸一元公式的码形成一个集合 (`codeSet`{.Agda})，在诞生处封印，隶属双向刻画 (`code∈codeSet`{.Agda}、`codeSet-out`{.Agda}、`codeSet-in`{.Agda}、`codeSet-spec`{.Agda})，这正是后继步所消费的覆盖那一半。每条码都是任何持有该载体的极限层的成员 (`code∈J`{.Agda})，故码集是该层的子集 (`codeSet⊆J`{.Agda})。该集合自身在下一个块内的隶属，无损失地归约到满足集引擎与一件具名的残留：块下方某层之上的一条公式，其可定义集就是码集 (`Description`{.Agda}、`codeSet∈block`{.Agda})。那条残留的兑付就是对象语言的码谓词，它是既有章节余下的内容，此处不再重造。
<!--/-->
