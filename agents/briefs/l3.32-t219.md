## WHAT THE DOCTRINE MUST ANSWER

1. **The taxonomy.** Group the episodes by MECHANISM, not by chapter.
   How many distinct diseases are there really? The LESSONS entries
   name P-k, P-l, R-35, R-38, I-4, I-5 and R-40; check whether the
   measured episodes actually reduce to fewer classes than that.
2. **The predictor.** Given a definition's SHAPE, before it is
   elaborated, what predicts that it will be expensive? Name the
   syntactic signatures a writer or a reviewer could check: an
   eliminator branch without a written type, a transparent
   presentation in a checked type, a premise with an iterated
   successor, a read lemma stopping one layer early. Rank them by the
   seconds each has actually cost.
3. **The rate.** Is there a defensible seconds-per-line figure for
   content of a given class? `[T191]`'s block 1 measured 6.3 s for 604
   lines; `[T195]`'s block 2 measured about 210 s for 948. **The ratio
   between those two is the most important unexplained number in the
   campaign.** Explain it: same master, same author, same laws cited,
   thirty-fold difference in cost per line. What is different about the
   content?
4. **The writing rules.** State the doctrine as rules a build brief can
   carry, each with the episode that measured it. A rule with no
   measurement behind it does not go in.
5. **The candidate laws.** Propose any new LESSONS entry the episodes
   support, with its measurement. The orchestrator assigns IDs; you
   propose the statement and the evidence.
