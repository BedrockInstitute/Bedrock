tier: codex (default). A read-only recon. It runs no Agda.

## GOAL

Ruling D36 caps the pure AC closure at 16,000 lines; the meter reads
RED with headroom **minus 3,541 naive**. The largest untapped lever is
intra-module fat: the trophy split is FILE-granular, so a shared master
in AC's closure bills ALL its lines to AC even when some definitions
serve only the GCH side. **Measure that fat, definition by definition.**

Run `.venv/bin/python scripts/ledger.py --trophy-files` for the parts.
The shared part is 31 masters, 9,203 lines. For each shared master, for
each top-level definition: find its consumers across the surviving tree
and classify. A definition is MOVABLE when no AC-side consumer reaches it
(directly or through other movable definitions): its only consumers are
gch-only masters, ambiguous masters, other movable definitions, or
nothing.

## METHOD

1. `--trophy-files` gives the four parts and marks the ten AMBIGUOUS
   masters. Treat ambiguous consumers as NON-AC (they are the rud
   engine's own consumers, in the shared part only by the neither-closure
   rule).
2. Extract each shared master's top-level names (the code fences; a
   definition's line count runs to the next top-level name).
3. Consumers by `rg -w` over `src/`, minus the module's own fences,
   plus a check of `open`/`renaming` re-exports, which hide consumers
   from a plain name grep. Say in the report how you handled re-exports.
4. Classify transitively: a definition consumed only by movable
   definitions is movable.
5. Sum movable lines per master. Report BOTH a conservative count
   (movable under every doubt resolved against moving) and an optimistic
   one (doubts resolved for moving), and say what each doubt is.
