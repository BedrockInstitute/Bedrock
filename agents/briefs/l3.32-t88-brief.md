## GOAL

`src/L/Ordinal/SquareLaw.lagda.md` is the **second-largest cost in the tree**:
**856 seconds over 907 code lines, 0.94 s/line against a tree average of
0.05**. Only Bridge is worse.

The ledger currently records its fix as **"unmeasured; assumed to respond like
Bridge, which is optimism until probed"**. That wording is deliberate: nobody
has measured it, and the assumption is doing no work until someone does.

**Measure it. Then price the fix in lines and in seconds.**

## THE PRECEDENT, AND WHY IT MAY OR MAY NOT TRANSFER

`[T86]` profiled Bridge at 939 s and found **95 percent of it was one family**:
`γ-compute`'s stated type ended at the tower body, so each of ten `subst`
consumers re-normalized the union tower inside `towerStep`, paying the same
conversion about eight times. The measured fix was **six lines for 769
seconds**: restate the read lemma to end where consumers actually use it, and
absorb the normalization once inside an `opaque` seal. `[T87]` is landing it now.

`[T86]` also diagnosed SquareLaw in passing, without measuring: it "states
memberships at concrete tower positions rather than at variable indices", the
I-4/I-5 class cost this project's own reports record as **reported, not cured**
(`_build/l3.32-t31-report.md:117`, `_build/l3.32-t47-report.md:170`).

**That diagnosis is a hypothesis, not a finding. Test it.** If SquareLaw's time
turns out to be spread thin rather than concentrated in one family, the
Bridge-shaped fix does not apply and the honest answer is that this 856 seconds
is expensive to remove. Say so if so.

## THE METHOD

1. **Profile it per definition**, the way T86 did Bridge: warm dependencies,
   its own interface moved aside, one process:
   `GHCRTS=-M8g agda --profile=definitions src/L/Ordinal/SquareLaw.lagda.md`.
   Report the top rows with their times.
2. **Establish the shape of the cost**: is it one family (Bridge's case), a
   handful, or a flat spread? That single fact decides everything downstream.
3. **If there is a concentrated cause, find it precisely.** For Bridge it was a
   read lemma stated one layer too early. Look for the analogue: a definition
   whose type forces its consumers to re-normalize something the definition
   itself could have absorbed.
4. **Try the fix in a scratch copy** (`/tmp`, module renamed as T86 did) and
   **measure the result**. An unmeasured proposal is not a deliverable here;
   T86's whole value was that it measured its own fix before proposing it.
5. **Report both dimensions**: lines added or removed, and seconds before and
   after, with the exact commands.

`[T47]` recorded **five heap exhaustions** while building this chapter, and
`[T31]` recorded one in the core's instantiation. **This chapter is the
project's most reliable way to kill the machine.** Run one Agda process, keep
`GHCRTS=-M8g`, and if a run dies on heap, that is a measurement to report, not
a reason to raise the cap.

this dispatch**; the Bridge fix kept every exported type intact and that is the
shape to aim for. If the only available fix changes exports, stop and report
it as a different, larger piece of work.
