# [L3.32-T190] Build the deletion test: D36's judgment, runnable on demand

tier: codex (default). A tooling task. It writes a script and its test.
**It runs no Agda**: siblings hold both slots.

## GOAL

Ruling D36 (as amended) makes the DELETION TEST the cap's pass-or-fail
judgment: at the AC landing, the AC endpoint must typecheck, exit 0, in
a tree with every gch-side master removed, and the surviving tree must
count under 16,000 non-blank in-fence lines. `[T147]` ran that test
once by hand. **Turn it into a tool**, so it can run at any time and at
the landing, and so the daily proxy's error is visible.

Write `scripts/deletion-test.py` with two modes:

1. **`--shadow` (default; no Agda, cheap).** Compute the AC-side file
   set exactly as `scripts/ledger.py`'s trophy split does (base +
   ac_only + shared, surviving tree, honoring `gch_assign`), report the
   count, the cap, the headroom, and the file list on request. Print
   the disclosure the board carries: this is file-granular, and
   `[T155]` measured the granularity error. Reuse `ledger.py`'s
   functions by import; do NOT re-implement the split (a second
   implementation would drift, which is the defect class this
   repository keeps finding).
2. **`--run` (the real test).** Create a git worktree at a temporary
   path, remove every gch-side master in it, generate a root module
   that imports every remaining AC-side master, typecheck it under
   `GHCRTS=-M8g`, report exit status, wall time and the count, then
   remove the worktree. **Guard it**: refuse to run when another Agda
   process is live (`pgrep -x agda`), print the expected cost, and
   require `--yes` to proceed, because a cold run costs minutes.

**Do not execute `--run` in this dispatch.** Verify the `--shadow`
path end to end, and verify `--run`'s guards by exercising every
refusal branch (no `--yes`, an Agda process live) without reaching the
typecheck.

## HOUSE RULES FOR SCRIPTS

- A module docstring that states WHY the tool exists and what it
  refuses, in this repository's voice (read `scripts/check-agents-guard.py`
  and `scripts/ledger.py` for the register).
- A test in `scripts/tests/` in the existing style (read
  `scripts/tests/test_dashboard.py`); it must cover the shadow count
  against `ledger.py --trophy-split`'s own number, so the two can never
  drift apart silently.
- `scripts/README.md` gains one section, in the file's existing shape.
- **Do NOT add the tool to `make check`.** It is a measurement, not a
  gate, and `--run` is far too expensive for the commit gate. Say this
  in the docstring.
- Run every `python3` as `.venv/bin/python`.
