## METHOD

```
GHCRTS=-M8g agda --profile=definitions <master>
```

**ONE AGDA PROCESS AT A TIME. This is not negotiable** (`dev/LESSONS.md`
C-12): concurrent typechecks thrash the machine and corrupt each other's
measurements, which would destroy the only thing you are being sent to
produce. Run the four in sequence. A heap exhaustion is a wall event to
report, never a reason to raise the cap.

For a warm per-definition profile, move the module's own `.agdai` aside so it
re-elaborates while its dependencies stay warm; restore it afterwards. The
pattern is recorded in `_build/l3.32-t86-report.md`'s appendix.

For each module, answer in this order:

1. **Where is the time?** The ranked per-definition table, top rows until you
   have 80% of the module's total. Name the definitions.
2. **Is it concentrated or flat?** A single family carrying most of the cost
   is the curable shape (`[T87]`: 95% in one family, 79% removed by six
   lines). A flat spread is a floor.
3. **If concentrated, what is the mechanism?** The three named diseases are in
   `dev/LESSONS.md` P-l: consumer-bound (a read lemma's type ends at the proof
   site rather than the consumption site, so consumers re-normalize),
   body-bound (assembly definitions elaborating delivered machinery at a
   concrete formula), or something you name yourself if neither fits.
4. **Is there an export-preserving cure, and what does it cost?**
   Export-preserving means every exported type is byte-identical afterwards.
   If the only cure changes an exported statement, say so explicitly and say
   which consumers would see it (`rg` for the names, report counts): that is a
   ruling for the owner, not a decision for you.
5. **Price it in seconds and lines, both directions.**

**A measured cure does not transfer by analogy** (`dev/LESSONS.md` P-l, and
this is the single most likely way this dispatch goes wrong). `[T87]`'s seal
worked on Bridge. `[T103]`'s telescope lift worked on SquareLaw. Neither is
evidence about `Pairing`. If you propose one of them, you must MEASURE it at
its own site in a scratch copy before calling it a price. An expected figure
anchored on a comparable elsewhere is a hypothesis, and must be labelled one.
