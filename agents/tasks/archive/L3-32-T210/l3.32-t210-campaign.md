## 2. What `L ⊨ AC` minimally requires

Derived from the delivered statement, read as mathematics (2026-08-08).

The theorem is `ChoiceStatement zf` (`src/L/Choice/Transversal.lagda.md:372-380`):
for every family `a : S` of pairwise-disjoint inhabited members, there
MERELY EXISTS (truncated) a constructible `c` meeting each member exactly
once. The carrier `S` is the constructible sets. So the obligation is:
produce ONE constructible transversal, under a propositional truncation,
with LEM available.

The minimal ingredient list, derived:

1. A well-order source covering the family's members' elements. The
   family `a` is arbitrary in `S`, so the source must cover every
   constructible set. By the immovable [T203] ruling the only
   syntax-free key lives on the S-tower, so the source is `Jset-order`
   and the family must LAND in the J tower: the cofinality statement
   `(x : S) -> isL x -> isJ x`. This is `bridge-isL→isJ`
   (`src/L/Rud/Bridge.lagda.md:1074`).
2. That cofinality proof needs STAGE MEMBERSHIP `Lset δ ∈ Sset (γ δ)`
   at every δ (the Q induction), NOT merely stage inclusion: a
   definable subset carves FROM the set `Lset δ`, so `Ldef→J`'s
   hypothesis is membership (`Bridge.lagda.md:1080-1083`). And Q's
   successor clause IS "the whole definable power as one set lands one
   block up" (`BlockPowLim`, `Bridge.lagda.md:976-978`), because
   `Lset (sucV β) = 𝒟ₒ (Lset β)` by the carrier's own definition.
   CONCLUSION: the brief's cofinality thread CLOSES NEGATIVE. A
   "some-J-level" statement does not avoid blockPowLim, because the
   successor step of any induction that lands stages is exactly
   Def-as-one-set. The expensive object is forced by the carrier's
   definition plus the immovable crossing, not by the plan's shape.
3. The order internalized as an object the model's separation can
   name: the carve's description must name the order internally
   ([T24]'s D-10 correction, recorded in the choice-rehome row). This
   is the w3-ac-slice content, re-formulated green by [T179] at 135
   probe lines.
4. The return crossing for the carved transversal: `c` is carved on
   the S side and must come home, so `bridge-isJ→isL` at `c`. Its
   induction (`Below`, `Bridge.lagda.md:1097-1171`) passes through
   limit indices below any J index, so `below-lim` is unavoidable,
   not only for the general theorem but for any single return at a
   J level (J indices are limits).
5. The pick and the carve themselves: measured green ([T3] 13 lines,
   [T24] ~130 carve).

COMPARISON TO THE PLAN: the five ledger rows map one-to-one onto
ingredients 1-5. The plan's SHAPE is the minimal shape under the
constraint set. The overage therefore cannot be closed by dropping an
ingredient; it must close inside each row's REALIZATION and inside

ONE DERIVED ESCAPE WORTH A PROBE, recorded honestly: the Reduce
