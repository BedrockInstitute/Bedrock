src/L/Rud/<master>.lagda.md` from the repository root, one Agda process at a
time (C-12), with the master's own `.agdai` moved aside first (P-p). The
dependency interfaces stay warm in `_build/2.8.0/agda/`. Every run exits 0
unless noted.

definitions postulated, `--safe` dropped in the copy only, cold for the copy
itself, one process. The copies are probe files and are never committed
(`scripts/check-probes.py`).

## Method

The masters are literate. The probes are plain `.agda` files woven from the
code fences of the masters by extraction, one probe per master. The weave
keeps the code verbatim; only the module name, the `OPTIONS` line and the
postulated bodies change.

in the copy, run cold for the copy, compare the total wall. The copy's
dependencies stay warm.
