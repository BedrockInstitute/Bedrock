## THE METHOD

1. **Worktree.** `git worktree add /tmp/t147-tree HEAD`. Work only there.
   The main tree is read-only to you.
2. **Remove the 22 masters** in the worktree.
3. **Build a fresh root file** instead of editing `Everything`: generate
   `/tmp/t147-tree/src/AllButGch.agda` that imports every remaining tracked
   master. This avoids the prose-unwiring hazard entirely.
4. **Typecheck the root**: `GHCRTS=-M8g agda src/AllButGch.agda` from the
   worktree, with the worktree's own `-i` paths.
5. **On failure**: record the breaking edge (which survivor, which missing

   green. **The set you had to drop, with its line count, is the true
   "falls with GCH-alone" set, and it is the report's central table.**
6. **Clean up**: `git worktree remove --force /tmp/t147-tree` when done.

## MACHINE DISCIPLINE, AND ONE HARD RULE

**A sibling codex agent `[T145]` runs Agda and MEASURES CHECK TIMES.** A
concurrent heavy typecheck contaminates its numbers. So: do all your
read-only preparation first (the worktree, the list reproduction, the root
file), and **before any long typecheck, wait until no other `agda` process
runs**: poll `pgrep -x agda` and sleep until it is empty. Your own runs use
`GHCRTS=-M8g`, one process. Your test is pass-or-fail, so a slower machine
does not hurt you; their test is a measurement, so you must not hurt it.

The worktree has no interface cache, so the first check is cold: expect
minutes, not seconds. That is fine.
