# [L3.32-T102] Dispatch 2's gate: can the `h₀` chain be stated without the tower presentation?

## 1. GREEN or RED

**GREEN.** The `h₀` pair can be stated without the tower presentation, the
generic module elaborates in **46 ms** inside the 8 GB cap, and the
in-place reshape in a faithful copy of the master drops the `h₀-inj` pair
from **374.3 s to 82 ms** (Total 450.9 s to 64.3 s) with no heap event and
no statement changed. The chain reshape is funded; dispatch 2b can be
written from the numbers in section 6.

The verdict is one controlled before/after pair on a byte-faithful scratch
copy of the current master (module renamed only, T88's control-copy method):
the only code change is the `AbstractH₀` insertion plus the four bodies
(`h₀`/`h₀-inj` in `Core` and `InitialCore`) becoming one-line
instantiations. Every signature is byte-identical to the master's (verified
by diff, section 4).

## 2. How many presentations the `h₀` statements carry

**Two nominal presentations, one of which is mechanically load-bearing, and
neither of which is the actual cost driver.** Quoted at `file:line`:

1. **`⟪ sucV (γp p) ⟫`**, the tower presentation, twice in `h₀`'s codomain
   (`src/L/Ordinal/SquareLaw.lagda.md:391`), inherited by `h₀-inj` through
   `h₀ p r pr ≡ h₀ p r' pr'` (`:399`). The tower is built from
   `γp p = ⟪ α ⟫↪ (max' (fst p) (snd p))` (`:388-389`), with
   `sucV N = N ∪ ⁅ N ⁆s` (Constructions.agda:161), `a ∪ b = ⋃ ⁅ a , b ⁆`
   (Constructions.agda:157), `⋃ S = sett (Σ[ r ∈ ⟪ S ⟫ ] ⟪ ⟪ S ⟫↪ r ⟫) ...`
   (Constructions.agda:110) and `⟪ X ⟫ = V-repr X .fst .fst`
   (Properties.agda:220-222): each `sucV` layer and each `⟪_⟫` application
   is a kernel-quotient layer (sett-repr, Properties.agda:147-158).
2. **`⟪ α ⟫`**, through the domain `PairA` (`Pair = ⟪ α ⟫ × ⟪ α ⟫`,
   Pairing.lagda.md:175), the order `r ≺' p` (`_≺₁_ m n = ⟪ α ⟫↪ m ∈ᵗ ⟪ α ⟫↪ n`,
   Pairing.lagda.md:80-81; `_≺_` at :177-180), `γp` (`SquareLaw.lagda.md:388-389`),
   the memberships `fst∈sucmax`/`snd∈sucmax` (`:342-343`, `:350-351`), and
   `h₀-inj`'s body's `↪-inj {a = α}` (`:404`, `:408`).

**But the count that matters is one, and it is not where the seconds sit.**
`⟪ α ⟫` is at a variable position (`α` is `Core`'s parameter), so it is a
stuck neutral and builds no tower. And the controlled pair (section 4)
proves the seconds do not sit in the *statements*: the byte-identical
concrete statements elaborate in **34 ms** in the master context once the
bodies pass the fiber and membership operations as neutral module
parameters. The cost driver was the bodies' concrete applications
`fiber β (fst∈sucmax {r} {p} pr)` at `β = sucV (γp p)`
(`SquareLaw.lagda.md:392-394`, `:400-408`), where elaborating `fiber`'s
codomain forces the normal form of `⟪ sucV (γp p) ⟫`. This corrects the
brief's premise (from T88 section 4a) that the family is statement-bound:
section 5 records why T88's gutted-body experiment was confounded.

The pair's statements inside it are `h₀ : (p : A × A) → (r : A × A) →

telescope. This is the real gate: T88's probe 2a (the chase's generic module
with the concrete source presentation left in the telescope) heap-exhausted

## 5. If RED: what walled, with the bisect

Vacuous: GREEN at every stage, no wall, no heap event (all exits 0 at
`-M8g`). The section is recorded because the bisect produced the report's
most important finding, which is a correction to the brief's premise.

The brief (following T88 section 4a) says the family is **statement-bound**:
T88 gutted `h₀-inj`'s body to a one-line application of a free generic
lemma and `h₀-inj` still paid its 190 s. The dispatch then asked whether
only a statement-level cure can reach it. My bisect shows the attribution
was confounded:

1. The same concrete statements, in the minimal context, with the ORIGINAL
   bodies, elaborate in **46 ms** (`ProbeT102H0Orig`, `/tmp/t102/orig.log`).
2. The same concrete statements, in the FAITHFUL master context, with the
   bodies passing fiber and memberships as neutral module parameters,
   elaborate in **34 ms** (`Core.h₀-inj`, `/tmp/t102/reshape.log`).
3. The only thing that changes the cost is whether the *bodies* apply
   `fiber β (fst∈sucmax ...)` at the concrete tower position
   (`SquareLaw.lagda.md:392-394`, `:400-408`).

T88's "gutted" body was not gutted of the expensive work: its one-liner
still passed the four concrete memberships `fst∈sucmax {a , b} {p} pr` at
`B := sucV (γp p)` as arguments to `fiber-pair-inj`
(`/tmp/t88/ProbeT88SquareLaw1c.lagda.md:393-398`), so the conversion
checks at the tower position were still inside the `h₀-inj` row. Moving
those operations into module parameters (checked once, at a neutral
metavariable position) removes the term entirely. The family is
**body-bound at the concrete fiber/membership applications**, not
statement-bound; the same `file:line` statements that cost 178.5 s in the
master cost 34 ms with the bodies reshaped. This is the answer to the
brief's question "does the result elaborate inside the 8 GB cap": yes, and
the 389 s was never a statement tax.

## 6. If GREEN: the measured price of the real build

**Lines.** The reshape is nearly line-neutral: non-blank in-fence lines go
906 (master copy) to 907 (reshaped copy), net **+1**. The diff is 31 lines
removed, 32 added. The net-new surface is `AbstractH₀`, 37 lines including
the 10-parameter telescope and both bodies
(`/tmp/t102/ProbeT102Reshape.lagda.md:51-87`); the four replaced bodies
(two per module) become one-line module applications
(`AbstractH₀.h₀ (⟪ α ⟫) (⟪ α ⟫↪) (↪-inj {a = α}) _≺'_ γp (⟪_⟫) (⟪_⟫↪)
fiber fst∈sucmax snd∈sucmax`). Dispatch 2b's brief: insert `AbstractH₀`
after the preamble (before `module FiniteBase`), replace the `h₀` and
`h₀-inj` bodies in `Core` (SquareLaw.lagda.md:391-410) and in
`InitialCore`'s `opaque` block (:1098-1117) with the one-line
instantiations, leave every signature and every consumer untouched. The
`opaque` block in `InitialCore` stays as it is; the instantiations compile
inside it (measured 48 ms).

**Seconds.** Minus 386.7 s on the module in one before/after pair on the
same machine (450.9 s to 64.3 s; the pair itself 374.3 s to 0.08 s). No
heap event at `-M8g`, no postulate, no hole, no termination pragma. The
`comp₀`/`comp₀-inj`/`exclude` consumers are untouched and remain cheap
(`comp₀` 35-47 ms, `comp₀-inj` 5.9-6.2 s after the reshape); dispatch 2b
does not need to move them for the seconds.

**Two implementation notes for dispatch 2b.** (1) The `↪F` parameter must
have an EXPLICIT binder, `(↪F : (a : S) → F a → S)`, not `{a : S}`: the
instantiation passes the definition `⟪_⟫↪` whose type has an explicit
first binder, and an implicit parameter makes the conversion check compare
an explicit with an implicit Π, which fails (`UnequalTerms`, section 4
bisect). (2) All ten module parameters are explicit; use positional
application in the master (named `{A = ...}` application of explicit
module parameters was rejected by this Agda inside the master context,
`WrongHidingInApplication`, while it is accepted in a minimal context; the
positional form is unambiguous and is what the measured reshape uses).
