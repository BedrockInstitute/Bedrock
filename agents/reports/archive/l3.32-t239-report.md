## 2. The new module

The home is `L.Rud.StepStory`. It is the sibling of the `Clause` module.
`L.LevelKit` is not the home.

StepStory is the S-story clause chapter. Its `Clause` module delivers the
successor clause at any carrier. The limit clause is the sibling clause
of the same story. `L.LevelKit` hosts the tower story's shared clauses.
The limit clause is not one of them. The kit has no `LEM` parameter. The
limit-clause decodes need `lem` for the two classical steps. StepStory
already has `lem`, the carrier, its transitivity and the kit. The new
module needs no telescope. D36 reads the same way. The limit clause
belongs next to the successor clause.

The module's header, copied from the master:

```agda
module Limit
  where

  -- The sixth clause, the limit clause: the value at a limit index is the
  -- pointwise union of the values below.  T128's meta statement, ported;
  -- nothing in it names a concrete carrier (src/ProbeT128.agda:143-147).
  limitClause : S → Type (ℓ-suc ℓ)
  limitClause f = (a b : S) → ⟨ isLimit a ⟩ → ⟨ pr a b ∈ˢ f ⟩
    → (z : S) → ⟨ z ∈ˢ b ⟩ ⟷ ∥ Σ[ ξ ∈ S ] (⟨ ξ ∈ˢ a ⟩
         × ∥ Σ[ w ∈ S ] (⟨ pr ξ w ∈ˢ f ⟩ × ⟨ z ∈ˢ w ⟩) ∥₁) ∥₁
```

The module's body is the port's body, line for line. It defines `limAt`,
`pairIn`, `inner7`, `unionRHS`, `limitConc`, `limitBody`, `limitForm`,
`_⊆_`, `ext-⊆`, `noAbove→succ`, `closedFromLim`, `nonemptyFromLim`,
`limAt-ok`, `unionRHS-ok`, `limit-ok`, `limit-out` and `limit-in`. All
are stated at the generic carrier `C`.

The one deviation from the brief's sketch: the meta-level clause is a
definition, not a parameter. A parameter cannot be eliminated. The `out`
direction must pattern match through `limitClause (fst f)`. An abstract
parameter leaves that application stuck. The clause statement is
carrier-independent. It is defined once in `Limit`. `Story`'s
`limitClause` in BelowLim re-exports it. The name, the type and the
consumers are unchanged.

No new master was added. `Limit` is a submodule of `L.Rud.StepStory`.
`src/Everything.lagda.md` needs no catalog change.
