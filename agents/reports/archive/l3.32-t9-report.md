## 2. T1: the count runs at the delivered shape (the D-10 truth check)

The target's exact shape is achievable. The encoding (`Count.code` in
`ProbeCard.agda`): the shape keeps every de Bruijn index as-is and turns each
constant occurrence into the marker variable at slot 1, so the shape lives in
`Formula ⊥* (nconst+1)` with the free variable still at slot 0; the tuple is
the constants in traversal order plus one padding copy of the first constant
(slot 1 is shared, so the tuple length is exactly nconst+1). The no-constant
case closes the free variable instead (`∃̇ (erase φ)`, k = 0). The decode
(`Count.decode`) reads the shape back: variables below the marker threshold
are kept, variables at or above it are constants consumed in traversal order.
The reconstruction lemma (`Count.decode-inv`, by induction on the formula)
proves `decode (code φ) = φ`, giving injectivity (`Count.code-inj`), packaged
as `Count.T1` — generic in the constant type K, which is *stronger* than the
target's instantiation at K = `⟪ A ⟫`.

Two findings about the exact shape, both positive:

1. **The free variable is not a constant.** The shape has nconst+1 slots
   (free variable plus constants) while the tuple has nconst constants; the
   stated Σ-type forces equal counts, so the tuple carries one padding entry
   (the first constant). This is a real constraint of the exact stated shape,
   not a hack: it is exactly what makes the shape-plus-tuple reconstruct the
   formula.
2. **The m = 0 case needs the erase-and-close branch.** The empty-carrier
   case (`Formula (⊥*) 1`, i.e. no constants) cannot pad, so it closes the
   free variable; this is the `erase`/`erase-inv` branch, which is where the
   D-10 "truth at the intended generality" check lives: the exact shape is
   true for every set A, including the empty carrier.

The count's cost is the finding that matters for the band: the encoding +
decode + reconstruction is **448 code lines**, over the gate's 400-line
stop-line. The mathematical content is real and constructive — this is not a
wall, it is a measured cost — but T5's implicit assumption that the count is
a "cheap" sub-item of the cardinal chapter is not supported: at the delivered
syntax, the count's full implementation (with its injectivity proof) is a
~450-line chapter component, not a free subroutine. The genuinely free part
T5 identified remains free (`Def-spec` refl gives the surjection onto
`𝒟ₒ A` at zero lines; the probe never touches it).

## 3. T2: the product bound walls — the ordinal-pairing chapter is the price

The target `Σ[ k ∈ ℕ ] (⟪ α ⟫ ^ k) ↪ ⟪ α ⟫` for infinite α reduces honestly
to the ordinal-pairing theorem. The probe proves the conditional core
(`Product.TupleCode`): given an injective pairing `pair : ⟪ α ⟫ × ⟪ α ⟫ →
⟪ α ⟫`, finite tuples inject into α, with the length marker `nat↪ (suc k)`
handled by the numerals' injection into α (`nat↪`/`nat↪-inj`, from `#∈ω`,
the transitivity of α, and `#-inj′`). The missing hypothesis — the pairing
itself — has **no in-tree raw material**:

- no ordinal arithmetic anywhere in `src/` (grep: `order-type`,
  `orderType`, ordinal addition/multiplication, `α × α`, pairing, initial
  ordinals: zero hits);
- no order-type / rank-into-ordinals theory: the delivered well-order
  bundle (`L.WellOrder.Base.SWO`) is trichotomy + well-foundedness only, with
  no order-type or rank comparison; `orderAt`'s construction (Choice/Step,
  Choice/Faithful) is a search, not an order-type theorem;
- the closest delivered comparable, `L.Choice.Finite`'s `Tally`, is
  finite-only (619 code lines), as T5 recorded.

The pairing theorem is a chapter of its own — the two classic routes are
ordinal arithmetic (`α·α = α`, absent) or order-type/initial-segment theory
(absent), either a 250-400-line build at the delivered shape (T5's own
red-consequence estimate, and consistent with the census: the nearest
comparable ordinal chapter, `L.Ordinal.Stages`, is 241 code lines). **The
truth of T2 is not in question** (it is classical), and the *target* is
faithfully reduced to a single missing theorem; the wall is the proof at the
delivered shape. The ordinal-pairing chapter is a valid and important result
in its own right: it is the κ·κ = κ core that every later cardinal step of
W7 (5.4's |M| = max(|X|,ω), 5.5's |L_α| = |α|, 5.6's |L_{κ+}| = κ+) consumes.
