## 2. D-10 verification of defects 2 and 3

Re-derived independently of T76, from the satisfaction clause
([Semantics.lagda.md:103](/Users/alsg/Agentic/Bedrock/src/FOL/Semantics.lagda.md))
and the de Bruijn convention (each binder prepends its witness,
[Syntax.lagda.md:96](/Users/alsg/Agentic/Bedrock/src/FOL/Syntax.lagda.md)).

**Defect 2: `snd∈Snd` asserts equality, the limit clause needs membership.**
At `(k, l)` the formula ([Condensation.lagda.md:396](/Users/alsg/Agentic/Bedrock/src/L/Condensation.lagda.md:396))
binds `x₁ ∈ k` (singleton), `y₂ ∈ k` (pair), `z ∈ y₂`, and reads
"`∀ u ∈ x₁: u ≠ z ∧ sndIn z l`". With `k = pr a b`: `x₁ = {a}`, `y₂ = {a,b}`,
so `u = a`, `a ≠ z`, and `sndIn z l` forces `z = snd(l)`; since `z ∈ {a,b}`
and `z ≠ a`, `z = b = snd(k)`. So `snd∈Snd k l` reads **`snd(k) = snd(l)`**.
The limit clause needs **`snd(k) ∈ snd(l)`**
(`limitClause`, [LevelFormula.lagda.md:152](/Users/alsg/Agentic/Bedrock/src/L/LevelFormula.lagda.md:152)).
Machine-checked at `p = pr ∅ one`, `q = pr ∅ two`: `snd(p) = one`,
`snd(q) = two`, `one ∈ two` holds, and the formula is **refuted** there
(`snd∈Snd-ref : ⟨ (p ∷ q ∷ []) ⊨ⱽ snd∈Snd f0 (suc zero) ⟩ → ⊥`,
`one∈two : ⟨ one ∈ˢ two ⟩`, `/private/tmp/T77Defects.agda`, exit 0). T76's
equal-case (`snd∈Snd-sat` at `(p, p)`) re-ran clean. **Defect 2 confirmed.**

**Defect 3: `limIn`'s second binder ranges over the singleton member.**
At `(p, f, x)` the formula ([Condensation.lagda.md:503](/Users/alsg/Agentic/Bedrock/src/L/Condensation.lagda.md:503))
binds `x₁ ∈ p` (singleton), then `∃̇∈ (var zero)` at :505 ranges over
**`x₁`** (the singleton), not the pair member of `p`. With `x₁ = {a}` this
forces the pair2 witness `y₂ = a` and the subset clause `x₁ ⊆ y₂` becomes
`a ∈ a`, refuted by irreflexivity; the rest of the clause is vacuous.
Machine-checked: `limIn-unsat : (f x : S) → ⟨ (p ∷ f ∷ x ∷ []) ⊨ⱽ limIn ⟩ → ⊥`
(`/private/tmp/T77Defects.agda`, exit 0; identical to T76's check F, re-run
clean). **Defect 3 confirmed.**

The intended reading of both clauses is the delivered one: every member of
the value `y` is the second component of a pair `pr b z ∈ f` with `b ∈ a`
([LevelFormula.lagda.md:245](/Users/alsg/Agentic/Bedrock/src/L/LevelFormula.lagda.md:245)),
which is what the rewritten limit clause must state and decode.

## 4. The decode discipline, demonstrated

The measured atom shows the shape the rewrite would use everywhere. For the
parameter-free pair atom, at the ambient reading:

```agda
prAtₚ : {n : ℕ} → Fin n → Fin n → Fin n → Formula (⊥* {ℓ}) n
prAtₚ q u v = (∃̇∈ (var q) (sglₚ f0 (suc u)))
          ∧̇ ((∃̇∈ (var q) (pairₚ f0 (suc u) (suc v)))
          ∧̇ (∀̇∈ (var q) (sglₚ f0 (suc u) ∨̇ pairₚ f0 (suc u) (suc v))))

prAtₚ-out : {n : ℕ} (q u v : Fin n) (δ : Vec S n)
          → ⟨ δ ⊨ₚ prAtₚ q u v ⟩ → lookup q δ ≡ pr (lookup u δ) (lookup v δ)
prAtₚ-in  : {n : ℕ} (q u v : Fin n) (δ : Vec S n)
          → lookup q δ ≡ pr (lookup u δ) (lookup v δ) → ⟨ δ ⊨ₚ prAtₚ q u v ⟩
```

and its clause-level consumer, the shared innermost decode:

```agda
pair∈ : {n : ℕ} (k a b : Fin n) (δ : Vec S n)
      → ⟨ δ ⊨ₚ ∃̇∈ (var k) (prAtₚ zero (suc a) (suc b)) ⟩
      ⟷ ⟨ pr (lookup a δ) (lookup b δ) ∈ˢ lookup k δ ⟩
```

Both directions typecheck in the probe (`/private/tmp/T77AtomRate.agda`,
exit 0). What this would have caught: a `sndIn`-style atom has no place in
this vocabulary at all, because the second-component relation is never
written by hand; `Rg` is "some pair `pr a x` lies in `f`" via `pair∈`, and
`pair∈` at a concrete pair is exactly the check that separates "x is the
second component" from "x is the first" (T76's checks B/C against
`(one, pr ∅ one)` / `(∅, pr ∅ one)`, re-verified here). The clause-level
defects need the clause decodes, not just the atom decodes: the limit
clause's decode against `limitClause` forces the binder structure (defect 3)
and the membership reading (defect 2), which is why the price includes the
limit clause decode explicitly. The delivered chapters show the same
discipline and produced no defect of this class: `L.Rud.LevelSigma`'s clause
decodes ([LevelSigma.lagda.md:217](/Users/alsg/Agentic/Bedrock/src/L/Rud/LevelSigma.lagda.md:217)),
PairAtoms' atom decodes, OpGraph's two-way graphs.
