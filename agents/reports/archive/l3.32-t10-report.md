## 5. The corrected gate target (D-10)

The gate's `mem2-out'` as transcribed, env `pt y y∈ :: pt a a∈ :: pt b b∈ ::
pt z z∈ :: []` with `mem2' = exists-in (var f2) (exists-in (var f2) (prAt' f2
f1 f0))`, is false: the first bounded existential ranges over
`lookup f2 [y,a,b,z] = b` and the second over `lookup f2 [p,y,a,b,z] = a`, so
the formula carves `{ pr p q | p in b, q in a } = F2 b a`, not `F2 a b`; neither
direction of the gate's statement is provable (witness swap fails on ordered
pairs). Priced before proof, per D-10. Corrected target (used): env `pt y y∈ ::
pt b b∈ :: pt a a∈ :: pt z z∈ :: []` - the chapter's own convention
(StepInL.lagda.md:1211-1250, env `z b a y`), which makes the first binder `a`
and the second `b`. The alternative correction (keep the env, swap the pair
clause to `prAt' f2 f0 f1`) carves the same set and is definitionally
isomorphic; not separately built.
