## 2. The tower and the two facts

`γ α = +ω (⋃_{δ<α} γ δ)` (Devlin's `γ(β) = ω·(β+1)`), sealed opaque at birth
with `γ-compute` as the only unfolding, one recursion covering zero
(`U-zero`: the union over the empty index is empty, so `γ ∅ = +ω ∅ = ω`),
successors (`γ-suc`: `γ (sucV β) ≡ +ω (γ β)`, the next ω-block) and limits
(verbatim). The two facts the induction needs:

1. `γ-lim : (α : S) → ⟨ isLimit (γ α) ⟩`, unconditionally: every value is
   `+ω` of the running sup, the sup is an ordinal over ordinal family members
   (`γ-ord`, also unconditional), and the delivered `+ω-limit` does the rest.
   This is what makes `Sset (γ β)` a J-level, so `BlockPowLim` and the full
   switch apply at the tower's own index.
2. `γ-suc : (β : S) → IsOrd β → γ (sucV β) ≡ +ω (γ β)`: the union over
   `sucV β` collapses to `γ β` (below by `γ-mono`, at the top by the union's
   own family membership).

The monotonicity kit is D-8's conditioned form, exactly T23's measured shape:
`sucV` is not subset-monotone (a counter-set exists), so the block map is
monotone only at ordinal arguments, where the trichotomy supplies the
membership. Kit: `sucV-mono-cond`, `sucIter-mono-ord`, `+ω-mono-ord`,
`γ-mono` (26 + 31 + 40 code lines as measured in the probe, laid out the same
here).

## 4. The survivor investigation: the old "unconditional" direction was
entangled with the false identification

This is the dispatch's finding, and it is a correction to the record. The
delivered chapter claimed `bridge-isJ→isL` is "delivered unconditionally from
`p4`". Tracing the proof:

1. `bridge-isJ→isL` uses `p4`'s inclusion half at the successor index
   `sucV δ` (the `Sset-out` index of the J-member).
2. The successor clause's inclusion needs `Sset δ ∈ Lset γ` (the common-stage
   membership feeding `Lstage₂`/`Lstep⊆`).
3. At a **limit** `δ`, that membership is `p4`'s limit-membership, proved in
   the delivered code by transporting through `p3 limδ : Lset δ ≡ Sset δ`
   (the per-level identification).
4. `p3`'s proof runs through `p2` (the ∀-over-limits membership), whose
   successor case uses `defStage∈J` (the false hypothesis).

Concrete instance: `x ∈ Sset (ω·3)` with `Sset-out` index `δ = ω·2` needs
`Sset (ω·2) ∈ Lset (ω·3)`, which the delivered proof gets from `p3` at
`ω·2` (`Lset (ω·2) ≡ Sset (ω·2)`, false content) via `p2` at `ω+1` via
`defStage∈J`. So the old "unconditional" delivery was conditional on the false
hypothesis; the landing could never have supplied it.

The identification-free limit-membership (`Sset β ∈ Lset γ` at limit `β ∈ γ`)
is the S-hierarchy's sequence as a member of the right constructible stage,
Devlin's carried sequence `⟨S_τ | τ ≤ ν⟩ ∈ L_{ωα}`, the same definability
family as `Q-lim` (the L-sequence in a rud level). It is carried as the second
named residue, `BelowLim` / `below-lim`, and the surviving direction
`bridge-isJ→isL` is delivered from the p3-free `Below` induction with that
residue: zero and successor memberships and all inclusions are proved from the
three true hypotheses; only the limit membership is parameterized.

**Proposed LESSONS entry (owner assigns the ID):** a delivered "unconditional"
half of a reduction can be entangled with a false clause through its
limit-membership; before reusing a surviving direction, trace its membership
at limit indices (the check that caught this took one hour of reading and
found the counter-instance at the second block).
