**The single fact that decides it.** The two orders are not the same
object. `Sset (α+1)` holds the values of **sixteen finitary operations**
at two arguments, so a well-founded key exists with no syntax: the
operation index, then the two arguments read from the previous order
(`src/L/Rud/Order.lagda.md:329-332`; T179's `codeLex`,
`_build/l3.32-t179-report.md:47-52`). `Lset (α+1)` is `𝒟ₒ (Lset α)`, the
**definable powerset**. Its members carry no finitary generation data, so
the only well-founded key is the **defining formula**, which is a name.
Ordering by names forces formula codes, an order on codes, and the
satisfaction of a code at an environment. That is the internalization
cone. The delivered chapter shows the forcing in its own text: the L-side
step description pins `codeOrder` and `AllCodes ∅ʟ` and concludes in
`StepAt` (`src/L/Choice/Order.lagda.md:184-187`).

ambient theory, not an element of the level, and no formula defines it"
(`src/L/Rud/Order.lagda.md:1014-1015`, quoted by T24 and T161).

### 3.2 The ideal form on today's survivors, and why it does not close

The brief names four survivors: `L.Rud.Order`, `L.Rud.OrderReadings`,
`L.Rud.SatSets`, `L.Rud.StepGraph`. All four order the **rud tower**.
`L.Rud.Order`'s comparison is stage, then operation index, then the two
arguments (`:329-332`). `L.Rud.StepGraph` supplies the sixteen membership
formulas and the sixteen-way disjunction. None of the four says anything
about `𝒟ₒ`, the definable-powerset step of the L tower.

To use them at an L stage you must first identify the L stage with a rud
closure. That identification IS the bridge. So route (b), "run the
carried order-story at the L carrier", is not a non-crossing route. T179's
own probe states its clause at `C = Lset β₀` with `β₀ = +ω a₀`, a level
chosen so that the identification holds, and it takes the values lex as a
module PARAMETER (`_build/l3.32-t179-report.md:43-44`, :169).

So the only genuine non-crossing shape is route (a): order `𝒟ₒ (Lset α)`
by names, L-natively. That is the delivered cone.

### 3.3 One escape checked and refuted

A syntax-free key looks available: order two definable subsets by the
least element of their symmetric difference, with birth stage first.
**It does not well-order.** Take `W = ω` and the subsets
`Xₙ = {n, n+1, …}`. For every `n`, `d(Xₙ, Xₙ₊₁) = n ∈ Xₙ`, so
`Xₙ₊₁ < Xₙ`, and the chain descends forever. The classical construction
uses least NAMES exactly because names inherit well-foundedness from the
code order. This is my reasoning with a counterexample, not a
measurement; it is flagged in section 7.
