## 1. POC 1: the forcing entry ticket

### 1.1 The headline finding: the validated recursor does NOT carry `val`

The W5 probe validated set-valued ∈-recursion over the HIT `V`
(`V.Hierarchy.∈-induction` at `P x = S` with `∈-induction-compute`,
`_build/w5-probe-report.md` §3). The brief asked whether that pattern carries
the two-place name recursion. **It carries one of the two recursions and not
the other, and the split is sharp:**

- **the check name `x̌ = { ⟨y̌, 𝟙⟩ | y ∈ x }` fits verbatim.** Its recursive
  call is at `y ∈ x`, ∈-depth 1. The W5 pattern is reused with no change:
  `chkStep` + `opaque chk` + `chk-compute`, 24 code lines including both
  readings (`ProbeForce.agda:115-150`).
- **the evaluation `val(τ,G) = { val(σ,G) | ⟨σ,p⟩ ∈ τ, p ∈ G }` does not.**
  The Kuratowski pair buries the name two levels down,
  `σ ∈ ⁅σ⁆s ∈ pr σ p ∈ τ`, so `val` needs its value at **∈-depth 3**, and
  `∈-induction` hands the IH at direct members only.

This is why the classical texts (Kunen VII §2) say "by recursion on rank". The
probe **proves the gap is real mathematics, not a formulation artifact**
(C-6 control, `ProbeForce.agda:84-93`):

```agda
name∉pair : (σ p : S) → σ ∈ᵗ pr σ p → Empty.⊥
```

Both branches of the pair's classification collapse to `σ ∈ σ` and die on the
hierarchy's regularity (`V.Hierarchy.∈-irrefl`, `src/V/Hierarchy.lagda.md:155`).
So no `∈ᵗ`-indexed induction hypothesis can *ever* reach the name.

### 1.2 The cure is 12 lines, and it reuses the same library recursor

The cure is not rank recursion and not a graph/fixpoint route. Because
`V.Hierarchy.∈-induction` is literally `WFI.induction regularityV`
(`src/V/Hierarchy.lagda.md:180`) — **generic in the well-founded relation** —
transporting well-foundedness along the transitive closure yields both the
recursor and its computation law for free:

```agda
data _∈⁺_ : S → S → Type (ℓ-suc ℓ) where
  here  : {y x : S} → y ∈ᵗ x → y ∈⁺ x
  there : {z y x : S} → z ∈⁺ y → y ∈ᵗ x → z ∈⁺ x

acc⁺ : (x : S) → Acc _∈ᵗ_ x → Acc _∈⁺_ x     -- 4 lines, structural on Acc
wf⁺  : WellFounded _∈⁺_
module ⁺I = WF.WFI wf⁺                        -- induction AND induction-compute
```

**12 code lines** (`ProbeForce.agda:94-110`), no `TERMINATING`, no postulate.
This is the single most transferable result of POC 1: the forcing entry
ticket's recursion problem costs twelve lines and zero new machinery, and the
same `⁺I` then carries *both* depth-3 recursions (`isName` into `hProp`, `val`
into `S`).

### 1.3 The index stays small: no resizing anywhere

`val`'s index is the nested small index, R-35-clean (no union representation
anywhere):

```agda
Idx τ = Σ[ m ∈ ⟪ τ ⟫ ] Σ[ j ∈ ⟪ e₁ τ m ⟫ ] Σ[ i ∈ ⟪ e₂ τ m j ⟫ ] Σ[ k ∈ ⟪ ∣G∣ ⟫ ]
          (e₁ τ m ≊ pr (e₃ τ m j i) (⟪ ∣G∣ ⟫↪ k))
```

Every component is `Type ℓ`: the three nested `⟪_⟫` are the library's small
member types, and the pair condition uses the library's **small equality**
`_≊_`/`_∼_`, which is exactly the delivered smallness atom
`V.Smallness.small-≡` (`src/V/Smallness.lagda.md:80`). **No resizing, no
impredicativity, no LEM is spent in POC 1 at all.** The D-7 constructive
intersection question never fires.

### 2.3 The mantle: one line to state, and a size wall that is the real remainder

```agda
Mantle : S → Type (ℓ-suc (ℓ-suc ℓ))
Mantle x = (W : Class) → IsGround W → ⟨ W x ⟩
```

**One line — and the typechecker itself reports the finding.** `Mantle` lands
in `Type (ℓ-suc (ℓ-suc ℓ))` because it quantifies over `Class`, so it is
**one universe too big to be a `Class`**. Therefore `𝒮ᵥ ↾ Mantle` does not
typecheck and **"𝕄 ⊨ ZFC" is not stateable at all** by the delivered
restriction operator. The probe names the debt explicitly:

```agda
MantleIsClass = Σ[ M ∈ Class ] ((x : S) → (⟨ M x ⟩ → Mantle x) × (Mantle x → ⟨ M x ⟩))
mantle⊨ : MantleIsClass → Type (ℓ-suc (ℓ-suc ℓ))
mantle⊨ (M , _) = M ⊨ZFC
```

This is precisely what the Laver–Woodin definability theorem is *for*, arriving
here as a universe-level obligation rather than a first-order one. It is the
single most important thing POC 2 found that the owner's note does not mention.

## 9. Lesson candidates

- **(candidate, extends R-35)** *Nested small indices are meta-poisoned in
  stored positions.* `⟪ ⟪ τ ⟫↪ m ⟫` — `⟪_⟫` applied to an eliminator
  application — is free in a term or a `sett` index and a 12 GB heap wall as a
  record/Σ field type. Three distinct cures failed, including I-4's prescribed
  carrier-level restatement; the only measured cure is to inline the
  decomposition at each use site and accept the duplication. Measured: 1.0 s
  inline versus heap-exhausted at 4:37, byte-identical mathematics.
- **(candidate)** *A recursion's ∈-DEPTH is a machine-checkable gate; measure
  it before pricing any set-theoretic recursion.* One 10-line theorem
  (`name∉pair`) converted "does the validated recursor carry this?" into a
  decided no, and the cure it forced was 12 lines because the tree's
  `∈-induction` is generic in its well-founded relation. Sibling of R2p's
  "measure the formula's Levy class before pricing a localization".
- **(candidate, extends D-16)** *A per-axiom model record at a bare-`Type`
  carrier is route-neutral capital and should be recognized as such.* The
  reason geology is free to state is that `ZFStructure` never demanded
  set-hood and `_↾_` never demanded smallness. The chapters that skipped D-16
  (`L/Coding`) pay; the chapters that observed it (`FOL/*`) are the only ones
  geology can bank.
