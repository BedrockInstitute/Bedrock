# [L3.32-T118] The visual pass: make the board feel designed

## 1. Design Read

Reading this as: a private single-reader engineering telemetry board for the
project owner, with a restrained tactical-monospace language, leaning toward
industrial-brutalist tactical telemetry: system font stacks, hard 90-degree
geometry, one amber accent, and a shared steel-blue chart ramp.

## 2. Skill choice

brutalist-skill, because it is the only library entry whose own description
covers data-heavy dashboards, and its Tactical Telemetry archetype is
dark-exclusive, monospace-dominant, high-density and zero-radius, which is
what this artefact is. taste-skill's own section 13 says "Not dashboards, not
data tables", so the flagship was rejected on its own text; its section 0
was still read first, as instructed.

## 3. What changed, by system

### Type

A real scale replaces the near-equal sizes: h1 at 1.75rem/700 with tight
tracking, h2 panel titles at 0.98rem/600 with an amber tick, h3 section
labels at 0.7rem uppercase mono with 0.14em tracking, body at 15px/1.5,
metadata at 0.72rem mono. Data speaks mono: stat numbers, table headers,
numeric cells, pie totals, legend values, edge labels, badges and source
notes all use the `--mono` stack with tabular figures, so columns of numbers
line up and the numbers read as the loudest element on the page
(scripts/dashboard.py:638 and the `td.num` cells it emits).

### Colour

The substrate moved from a neutral grey to a deactivated-CRT charcoal blue
(`--bg #0b0e12`, `--card #11151b`, `--sunk #0d1117`), the warn red was
desaturated, and the chart palette changed from a rainbow of seven pastels to
one steel-blue slice ramp (`--pie-1` through `--pie-6`, `--pie-tail`) plus the
amber `--pie-standing` for the measured standing slice. The amber accent is
now semantic, not decorative: it marks the current position, the measured
stats (`stat measured`), decisions, and the standing slice in the line pies.
Every colour remains a `:root` variable; a mechanical check in
scripts/tests/test_dashboard.py asserts no hex literal survives outside the
theme block.

### Space and rhythm

One corner system: zero border radius everywhere, per the chosen skill's
geometry rule. Panel padding and gutters grew slightly (18px/20px panels,
24px/28px page, 20px grid gap), h3 sections get 18px of air above them, and
the tree rows breathe at 3px vertical padding with a hover tint. The pie
cards gained a header rule, and the measured stat cards carry a 2px amber
left edge while estimate cards carry a neutral one, so the reader's eye lands
on measured numbers first.

### Charts

The pies now share one visual language: the same steel ramp, the same
background-colour stroke between slices (2px, pinned in CSS), square legend
swatches with a hairline border, mono legend values, and the total always in
amber mono. The two line-distribution pies and the two seconds pies are
visibly the same instrument.

### Route graph

The graph reads as a graph: each edge line starts with a small square
junction marker, edge labels are uppercase mono, decision nodes keep their
dashed amber line, the start node keeps its steel-blue fill with a 2px amber
outline when the current position is on it, and node hover shifts the surface
so the reader can track a branch while scanning.

## 5. What a skill told me to do that I did NOT do

1. **CRT scanlines and global noise/grain** (brutalist-skill section 7):
   skipped. This board is read several times a day for signal, and a
   repeating-gradient texture over 96 tree rows and a dense route graph would
   fight legibility instead of adding atmosphere. Restraint is the point of
   the exercise.
2. **Macro-typography at `clamp(4rem, 10vw, 15rem)`, uppercase, compressed
   leading** (brutalist-skill section 3.1): skipped. That scale is for a
   poster; here the numbers are the loudest element, so they get the scale
   budget instead, and every heading stays sentence case because the titles
   are long statements, not slogans.
3. **Aviation red as the single accent and terminal green for exactly one
   element** (brutalist-skill section 4): declined. The status badges are
   data, not decoration: green means done, amber means active, blue means
   planned. Collapsing them to one colour would delete information the
   arrangement stage decided to carry. The amber accent is kept and made
   semantic instead.
4. **Official design-system package (Fluent, Carbon)** (taste-skill section
   2.A for dashboards): impossible and unnecessary. The page must stay
   offline, static and dependency-free, and a system font stack plus native
   CSS is what the constraints allow; taste-skill itself says to say so
   explicitly and apply only what fits.
5. **Web fonts and icon libraries** (taste-skill sections 3.A and 3.C):
   skipped for the same reason, per the hard constraint that forbids web
   fonts, icon sets and any network reference.
