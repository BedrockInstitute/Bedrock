The cure names the in-direction's two branches.  They become top-level
functions with written types.  The eliminator receives the names.

```agda

segDom-in-below a a∈a₀ = ∣ Sset a , prξSξ∈seg₀ a a∈a₀ ∣₁

segDom-in-top : (a : S) → a ≡ a₀ → ∥ Σ[ b ∈ S ] ⟨ pr a b ∈ˢ seg₀ ⟩ ∥₁
segDom-in-top a a≡a₀ = ∣ Sset a₀ , subst (λ w → ⟨ pr w (Sset a₀) ∈ˢ seg₀ ⟩) (sym a≡a₀) T∈seg₀ ∣₁

segDom-in : (a : S) → ⟨ a ∈ˢ sucV a₀ ⟩
         → ∥ Σ[ b ∈ S ] ⟨ pr a b ∈ˢ seg₀ ⟩ ∥₁

  (segDom-in-below a) (segDom-in-top a)
```

The class is I-5.  The pinned implicits are not required.  The named
