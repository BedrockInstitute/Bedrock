existence yields the least index, after the least-witness type is proved to
be a proposition. There is no host choice or dependent-choice hypothesis.

sets with data-valued coverage. Each descending step uses `leastOf`. The
generated subset is a filter and meets every coded dense set, which is
`CodedCompletion.isGeneric`.

enumeration with pointwise truncated coverage, using least-index uniqueness.
A truncated existence corollary returns truncated generic existence and does
not extract a filter from mere truncation.

starting condition, with the same parameters as `K9.NameGround`.
