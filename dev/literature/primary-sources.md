## 1. Jensen: rud, basis, S/J indexing, simple functions (JM)

### 1.1 The rud definition (JM Definition 2.2.1, p. 49)

> Definition 2.2.1. f : V^n → V is a rudimentary (rud) function iff it is
> generated by successive applications of schemata (i) - (v) in the definition
> of primitive recursive in chapter 1, §2.

JM preamble, p. 49, also gives the Gandy attribution:

> These functions, which were discovered by Gandy and Jensen, are exactly the
> functions which are generated by the schemata for primitive recursive
> functions when the recursion schema is omitted.

For the explicit schemas (i)-(v) in print, see Dev VI.1 (section 2.1 below);
SZ Definition 1.1 (p. 6, in the L1 notes) gives the six-schema presentation.

### 1.2 The finite basis (JM Theorem 2.2.15, p. 56)

> Theorem 2.2.15. The following functions form a basis for the rud function:
>
>     F0(x, y) = {x, y}
>     F1(x, y) = x \ y
>     F2(x, y) = x ⊗ y
>     F3(x, y) = {(u, z, v) | z ∈ x ∧ (u, v) ∈ y}
>     F4(x, y) = {(u, v, z) | z ∈ x ∧ (u, v) ∈ y}
>     F5(x, y) = ⋃ x
>     F6(x, y) = dom*(x)
>     F7(x, y) = {(z, w) | z, w ∈ x ∧ z ∈ w}
>     F8(x, y) = {x*z | z ∈ y}

with JM Definition 2.2.8 (p. 56): "x ⊗ y = {(z, w) | z ∈ x ∧ w ∈ y};
dom*(x) = {z | ∃y (y, z) ∈ x}; x*z = {y | (y, z) ∈ x}."

The relativized basis (JM Corollary 2.2.16, p. 60):

> Let A1, ..., An ⊆ V. Then F0, ..., F8 together with the functions
> a_i(x) = x ∩ A_i (i = 1, ..., n) form a basis for the functions which are
> rudimentary in A1, ..., An.

The comprehension bridge (JM Corollary 2.2.14, p. 55): "Def(U) = P(U) ∩ Rud(U)
if U ≠ ∅ is transitive", where (JM Definition 2.2.6, p. 54) Rud(U) = rud(U ∪
{U}).

Cross-check against the corpus: JM's F0..F8 are exactly SZ's F0..F8 (SZ p. 10),
and SZ footnote 5 (p. 10) says their F0..F15 list "contains more functions than
the list from [3, Lemma 1.8]". The 1972 journal text of Lemma 1.8 itself was
NOT fetched (ScienceDirect bot wall; section 6). JM's list is Jensen's own later
account of his basis, not a scan of the 1972 paper: the notes treat it as JM,
not as the 1972 wording.

### 1.3 The J- and S-hierarchies and the indexing conventions

JM Definition 2.3.1 (p. 64):

> J_ω = Rud(∅); J_{α+ω} = Rud(J_α) for α ∈ Lm; J_λ = ⋃_{ν<λ} J_ν for λ a
> limit point of Lm.

JM p. 49 records the earlier indexing convention (the manuscript itself uses
Sy Friedman's limit-ordinal indexing):

> Note. This indexing was introduced by Sy Friedman. In [FSC] we indexed by
> all ordinals, so that our J_{ωα} corresponds to the J_α of [FSC]. The usage
> in [FSC] has been followed by most authors. Nonetheless we here adopt
> Friedman's usage, which seems to us more natural, since we then have:
> α = rn(J_α) = On ∩ J_α.

Flag: [FSC] is not mapped in the fetched JM bibliography files; the standard
identification with the 1972 Annals paper is not asserted here as a fetched
fact, only the sentence above is reported.

The S-hierarchy (JM Definition 2.3.4, p. 66): "S_0 = ∅; S_{ν+1} = S(S_ν);
S_λ = ⋃_{ν<λ} S_ν for limit ν", and "Obviously then: J_α = S_α for α ∈ Lm".
Here S(U) = s(U ∪ {U}) (JM Corollary 2.3.3, p. 66) and s is the single rud
function of JM Lemma 2.3.2 (p. 65), with (b) "rud(U) = ⋃_{n<ω} s^n(U)". JM
2.3.4 adds: "It would be tempting to simply define J_ν = S_ν for all ν ∈ On.
We avoid this, however, since it could lead to confusion: At successors ν the
models S_ν do not have very nice properties. Hence we retain the convention
that whenever we write J_α we mean α to be a limit ordinal."

Relativized hierarchies: JM Definitions 2.3.8, 2.3.10, 2.3.11 (pp. 70-71) give
J_α^A and S^A with S^A(u) = S(u) ∪ {A ∩ u}.

### 1.4 Simple functions and their complexity role (JM 2.2)

> Definition 2.2.2. f : V^n → V is simple iff whenever R(z, ~y) is a Σ0
> relation, then so is R(f(~x), ~y).

> Lemma 2.2.3. All rud functions are simple.

> Corollary 2.2.4. Every rud function f is Σ0 as a relation. Moreover f^U is
> uniformly Σ0(U) whenever U is transitive and rud closed.

> Corollary 2.2.5. Every rud relation is Σ0.

> Corollary 2.2.8. Every function f which is rud in A is Σ1 in A as a
> relation. Moreover f^U is Σ1(⟨U, A∩U⟩) by the same Σ1 definition whenever
> ⟨U, A∩U⟩ is transitive and rud closed.

JM section 2.6 "Σ*-theory" (pp. 99 ff.) develops the typed-variable hierarchy
(variables of Type 0, Type 1, ...) and the projecta, but does not re-introduce
the term "simple functions" there (the only "simple" occurrence in 2.6 is a
prose "simple induction"). So the fetched JM text supports simple functions as
the Σ0-preservation device of section 2.2, and gives the Σ0 / Σ1 complexity
bounds above; the owner-note claim that simple functions "serve the Σ*-theory"
is NOT supported by the fetched JM text and stays unverified (digest OPEN item
4; Zeman's book would settle it, still unfetched).

## 2. Devlin, "Constructibility" (Dev)

### 2.1 Where the rud functions live

Dev Chapter I itself points forward (Dev I, p. 7): "A particular example
occurs in VI.1, where we discuss the rudimentary functions." Chapter II's
exercise 1 defines the term (Dev II, p. 100): "(Functions generated by schemas
(i) through (v) are said to be rudimentary, and play a basic role in our later
work on constructibility theory.)" The full treatment is Dev VI.1 (pp. 225-226):

> A function f : V^n → V is said to be rudimentary (rud for short) iff it is
> generated by the following schemas:
>
> (i)   f(x1, ..., xn) = xi (1 ≤ i ≤ n);
> (ii)  f(x1, ..., xn) = {xi, xj} (1 ≤ i, j ≤ n);
> (iii) f(x1, ..., xn) = xi - xj (1 ≤ i, j ≤ n);
> (iv)  f(x1, ..., xn) = h(g1(x1, ..., xn), ..., gk(x1, ..., xn)), where
>       h, g1, ..., gk are rudimentary;
> (v)   f(y, x2, ..., xn) = ⋃_{z ∈ y} g(z, x2, ..., xn), where g is
>       rudimentary.

Dev VI.1, p. 226, adds: "(vi) f(x1, ..., xn) = A ∩ xi (1 ≤ i ≤ n)" for
rudimentary relative to A (A-rud), and "(vii) f(x1, ..., xn) = p" for
rudimentary in parameter p.

### 2.2 The named theorem: Basis Lemma (Dev VI.1.11, p. 236)

> 1.11 Lemma (The Basis Lemma). Every rudimentary function is a composition of
> some or all of the following rudimentary functions:
>
>     F0(x, y) = {x, y}
>     F1(x, y) = x - y
>     F2(x, y) = x × y
>     F3(x, y) = {(u, z, v) | z ∈ x ∧ (u, v) ∈ y}
>     F4(x, y) = {(u, v, z) | z ∈ x ∧ (u, v) ∈ y}
>     F5(x, y) = ⋃ x
>     F6(x, y) = dom(x)
>     F7(x, y) = ∈ ∩ (x × x)
>     F8(x, y) = {x"{z} | z ∈ y}

The relativized version (Dev VI.1.12, p. 241):

> 1.12 Lemma (Extended Basis Lemma). Let A ⊆ V, and define F9 by
> F9(x, y) = A ∩ x. Then every A-rudimentary function may be expressed as a
> composition of some or all of the A-rud functions F0, ..., F9.

Errata caveat (inline): this is exactly the section Devlin got wrong per
Mathias's inventory (WS section 10, WS p. 56: the flaws are "chiefly confined
to section 9 of Chapter I and section 1 of Chapter VI"; full checklist in
devlin-errata.md). Dev VI.1 is quoted here as fetched text, not certified; do
not use it as a blueprint without the errata checklist open.

### 2.3 The Jensen hierarchy in Devlin (indexed by all ordinals)

Dev VI.2, p. 251:

> The Jensen hierarchy, (J_α | α ∈ On), is defined by the following recursion:
> J_0 = 0; J_{α+1} = rud(J_α); J_λ = ⋃_{ν<λ} J_ν, if lim(λ).

Dev Lemma 2.1(iii), p. 252: "rank(J_α) = J_α ∩ On = ωα." Dev VI.2 (p. 252)
defines the S-subhierarchy and Lemma 2.2(ii) states: "J_α = ⋃_{ν<ωα} S_ν =
S_{ωα}." This all-ordinal indexing is Devlin's (and Jensen's 1972) convention,
contrasted with SZ's limit-ordinal indexing (SZ footnote 4, p. 9, in the L1
notes).

### 2.4 "Gödel operations" in Devlin

The phrase "Gödel operations" does not occur in the fetched Dev chapters I, II,
or VI (full-text searches; the only "Gödel" hits are "Gödel pairing function",
Dev VI.3.17, p. 266, and "theory of Godel", Dev II, p. 57). Devlin's named
statement relating rud functions to a finite function list is therefore VI.1.11
(section 2.2 above). The digest's "chapter I" attribution for this statement is
corrected on the fetched evidence: Chapter I only carries the p. 7 pointer, the
term is introduced in a Chapter II exercise (p. 100), and the theorem lives in
Chapter VI.

## 3. Jech, "Set Theory" (3rd millennium ed.), ch. 13

### 3.1 The L-hierarchy (Jech Definition 13.1, p. 175)

> Definition 13.1. We define by transfinite induction
> (i) L0 = ∅,
> (ii) L_{α+1} = def(L_α),
> (iii) L_λ = ⋃_{α<λ} L_α if α is a limit ordinal, and
> L = ⋃_{α∈Ord} L_α.
> The (definable) class L is the class of constructible sets. The statement
> V = L, i.e., "every set is constructible," is the Axiom of Constructibility.

### 3.2 The Gödel operations and their named statements

Jech Theorem 13.4 (Gödel's Normal Form Theorem), p. 177:

> There exist operations G1, ..., G10 such that if φ(u1, ..., un) is a Δ0
> formula, then there is a composition G of G1, ..., G10 such that for all
> X1, ..., Xn,
> (13.1) G(X1, ..., Xn) = {(u1, ..., un) : u1 ∈ X1, ..., un ∈ Xn and
> φ(u1, ..., un)}.

Jech p. 177, immediately after: "Compositions of G1, ..., G10 are called Gödel
operations."

Jech Definition 13.6 (Gödel Operations), p. 178:

> G1(X, Y) = {X, Y},
> G2(X, Y) = X × Y,
> G3(X, Y) = ε(X, Y) = {(u, v) : u ∈ X ∧ v ∈ Y ∧ u ∈ v},
> G4(X, Y) = X - Y,
> G5(X, Y) = X ∩ Y,
> G6(X) = ⋃ X,
> G7(X) = dom(X),
> G8(X) = {(u, v) : (v, u) ∈ X},
> G9(X) = {(u, v, w) : (u, w, v) ∈ X},
> G10(X) = {(u, v, w) : (v, w, u) ∈ X}.

Jech Corollary 13.8, p. 181:

> For every transitive set M, def(M) = cl(M ∪ {M}) ∩ P(M), where cl denotes
> the closure under G1, ..., G10.

Jech Theorem 13.9, p. 182:

> A transitive class M is an inner model of ZF if and only if it is closed
> under Gödel operations and is almost universal, i.e., every subset X ⊂ M is
> included in some Y ∈ M.

Jech Lemma 13.14, p. 187: "The function α → Lα is Δ1", with the induction step
(13.11), p. 187: "Y = cl(M) (where cl denotes closure under Gödel operations)
is Σ1". Jech Theorem 13.16 (Gödel), p. 187: "(i) L satisfies the Axiom of
Constructibility (V = L). (ii) L is the smallest inner model of ZF."

### 3.3 Relationship to the rud route

Jech's closure cl is closure under the ten Gödel operations G1..G10; JM's
Rud(U) is closure under the rud functions; both satisfy the same comprehension
identity: Jech Corollary 13.8 (def(M) = cl(M ∪ {M}) ∩ P(M)), JM Corollary 2.2.14
(Def(U) = P(U) ∩ Rud(U)), and SZ Lemma 1.4 (P(U) ∩ rud_A(U ∪ {U}) = P(U) ∩
Σ_ω^{⟨U,∈,A⟩}, p. 8, in the L1 notes). No fetched text states the literal
sentence "rud = compositions of the Gödel operations"; the named statements
above (Jech 13.4, 13.8; Dev 1.11; JM 2.2.15) are what the fetched corpus
actually provides.
