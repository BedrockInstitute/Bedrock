## 1. The contemporary rud basis (Q1)

### 1.1 Schindler-Zeman: schemata presentation

SZ Definition 1.1 (p. 6), verbatim (symbols restored):

> Let A be a set or a proper class. A function f : V^k -> V, where k < omega,
> is called rudimentary in A (or, rud_A) if it is generated by the following
> schemata:
>
> f(<x1, ..., xk>) = xi
> f(<x1, ..., xk>) = xi \ xj
> f(<x1, ..., xk>) = {xi, xj}
> f(<x1, ..., xk>) = <g1(<x1, ..., xk>), ..., g_l(<x1, ..., xk>)>
> f(<x1, ..., xk>) = union_{y in x1} g(<y, x2, ..., xk>)
> f(x) = x ∩ A
>
> f is called rudimentary (or, rud) if f is rud_empty.

So SZ's basis is: projection, set difference, unordered pair, tuple/composition,
bounded union, and (for the relativized class) the single additional schema
x ∩ A. See also SZ 1.2 Definition (p. 7): a relation R is rud_A iff R = {x~ ;
f(x~) != ∅} for some rud_A function f.

SZ 1.3 Proposition (p. 7) lists closure properties: member-of is rud; conditional
definition by rud relations; intersection; membership in A is rud_A (clause (d));
characteristic functions; complement; bounded separation y ∩ {z ; R(z, x~)};
bounded quantification. These closure properties are what make the "comprehen-
sion" direction of Lemma 1.4 go through (see section 4).

### 1.2 Schindler-Zeman: the finite basis F0..F15 for the S-hierarchy

SZ pp. 9-10, for the auxiliary hierarchy S^A:

> S^A(U) = union_{i=0}^{15} Fi"(U ∪ {U})^2

with (verbatim list):

    F0(x, y)   = {x, y}
    F1(x, y)   = x \ y
    F2(x, y)   = x × y
    F3(x, y)   = {<u, z, v> ; z ∈ x ∧ <u, v> ∈ y}
    F4(x, y)   = {<u, v, z> ; z ∈ x ∧ <u, v> ∈ y}
    F5(x, y)   = union x
    F6(x, y)   = dom(x)
    F7(x, y)   = ∈ ∩ (x × x)
    F8(x, y)   = {x"{z} ; z ∈ y}
    F9(x, y)   = <x, y>
    F10(x, y)  = x"{y}
    F11(x, y)  = <left(y), x, right(y)>
    F12(x, y)  = <left(y), right(y), x>
    F13(x, y)  = {left(y), <right(y), x>}
    F14(x, y)  = {left(y), <x, right(y)>}
    F15(x, y)  = A ∩ x

SZ then state (p. 10):

> It is not difficult to show that each Fi, 0 ≤ i ≤ 15, is rud_A. A little bit
> more work is necessary to show that every rud_A function can be generated by
> using functions from this list. The functions Fi, 0 ≤ i ≤ 15, are therefore a
> basis for the set of rud_A functions (cf. [3, Lemma 1.8]).

Footnote 5 (p. 10) is load-bearing for Q1:

> The above list in fact contains more functions than the list from [3, Lemma
> 1.8]; this enlargement yields the transitivity of each S^A_alpha.

Here [3] is Jensen 1972 (SZ bibliography, p. 57). Jensen's own list is NOT
reproduced verbatim anywhere in the fetched material; the only directly
verifiable statements about it are this footnote and the F0..F15 list above.
Marked: Jensen's original list itself = not determinable from fetched text.

### 1.3 Mathias-Bowler: the corrected list R0..R8

MB section 2 (preprint p. 13), verbatim definitions:

    R0(x, y) = {x, y}
    R1(x, y) = x \ y
    R2(x)    = union x
    R3(x)    = Dom(x)
    R4(x, y) = x × y
    R5(x)    = x ∩ {(a, b)2 | a ∈ b}
    R6(x)    = {(b, a, c)3 | (a, b, c)3 ∈ x}
    R7(x)    = {(b, c, a)3 | (a, b, c)3 ∈ x}
    R8(x, y) = {x"{w} | w ∈ y}

MB 2.0 DEFINITION (p. 13), verbatim:

> Let R, the collection of rudimentary functions, be the closure of R0 . . . R8
> under composition. Let B, the collection of basic functions, be the closure of
> R0 . . . R7 under composition.

The auxiliary functions A0..A14 (e.g. A14(x,y) = x"{y}) are generated from the
Ri by composition (MB p. 13). MB 2.1 PROPOSITION: "(i) For each Δ0 class A the
map x -> x ∩ A is in B." MB 2.2: branching over Δ0 choices is coded by a
rudimentary function (explicit expression, p. 13).

The same list appears in WS 2.61 (pp. 19-20), which adds:

> Corresponding to the systems of DB0 and GJ0, we introduce the rudimentary
> functions R0, . . . R8 and certain auxiliary functions A0 . . . A15 generated by
> them: this is not the shortest possible list, but one that conveniently extends
> the list that generates the Δ0 separators.

WS 2.63-2.68: B = closure of R0..R7; R = closure of R0..R8; each function in B
is DB0-suitable; each function in R is GJ0-suitable; "For each Δ0 class A the
map x -> x ∩ A is in B" (2.65).

Fr slide 6 repeats the same R0..R8 list.

### 1.4 The weak systems and the "one added function" history (Q1, Q5)

WS 1.10 (p. 10), verbatim:

> If we add the axiom of infinity plus the scheme of foundation for all classes
> to DB we obtain the system BS as formulated on page 36 of Devlin's book
> Constructibility: BS = ReS0 + Cartesian product + full foundation + ω ∈ V.

WS 1.12 REMARK (p. 11), verbatim:

> GJ0 is the result of adding a single axiom, which I call R8, to DB0:
> (R8) {x"{w} | w ∈ y} ∈ V.

So the "Gandy/Jensen extra function" relative to the Devlin Basic list is R8,
the image function {x"{w} | w ∈ y}. MB 1.49 (p. 12) gives the history:

> We now reach a system of the greatest importance in the study of
> constructibility, which was discovered independently by Gandy [G] and by
> Jensen [J2]. The transitive models of this system are precisely the transitive
> sets closed under a certain collection R of functions, which we have yet to
> define. The members of this collection were called basic by Gandy and
> rudimentary by Jensen; the second adjective has been generally adopted in the
> literature, and is customarily shortened to rud.

MB 1.50-1.55 (p. 12): GJ0 = DB0 + {x"{w} | w ∈ y} ∈ V; GJ = GJ0 + Π1
foundation; GJI = GJ + ω ∈ V. MB 1.54: "MW is a subsystem of GJI." MB 1.55:
"§6 of [M3] recalls the result of Gandy [G] that GJI does not prove the
existence of S(ω)." (S(x) = the set of finite subsets of x, WS 0.0, p. 5.)

WS 2.85 PROPOSITION (p. 23), verbatim:

> (Gandy; Jensen) A transitive set is rud closed (= basically closed) iff it
> models GJ0.

WS 2.87: "Δ0 separation is a theorem scheme of GJ0." WS 2.88: RR is
self-strengthening to (RR+). WS 2.90-2.91: (GJ0) each [a]^k exists; (GJ)
∀a∀k∈ω [a]^k ∈ V. WS 2.93: (GJ) ∀a∀m∈ω ^m a ∈ V (functions from m to a).

WS 1.13 REMARK (p. 12): the axioms of ReS0, DB0, GJ0, fReR0, fReC0 "are all
provable in the system M0 studied in [M2], which is the system ReS0 + the power
set axiom, P(x) ∈ V".

### 1.5 Which basis is "contemporary"? (Q1 synthesis)

- SZ (the orthodox contemporary survey) use the schemata of Definition 1.1:
  projection, difference, pairing, composition, bounded union, plus x ∩ A for
  relativization. For the S-hierarchy they use the 16-function finite basis
  F0..F15 (SZ p. 10), explicitly an enlargement of Jensen's [3, Lemma 1.8]
  list (footnote 5).
- MB/WS (the corrected modern treatment) use R0..R8, where R8 = the single
  added function beyond the Devlin Basic generators, and B (R0..R7) generates
  exactly the Δ0 separators (MB 2.0-2.1; WS 2.63-2.68).
- The raw sweep's phrase "Gandy and Jensen each adding one function" is not
  verbatim in the fetched text; what IS fetched is WS 1.12 (GJ0 = DB0 + R8) and
  WS 2.61 (R8 is the distinguishing axiom). The Bernays provenance is WS p. 10:
  "as it thereby becomes finitely axiomatisable, by a result of which many
  variants are found in the literature, and presumably going back to Bernays",
  and MB 1.43 THEOREM (Bernays): "All instances of Δ0 separation are provable in
  the system DB0."

## 2. Rud closure, the T function, and the J-hierarchy connection

WS 2.73 DEFINITION (p. 21): the unary function T(u) = u ∪ {u} ∪ [u]^1 ∪ [u]^2
∪ {x \ y | x,y ∈ u} ∪ {union x | x ∈ u} ∪ {Dom(x) | x ∈ u} ∪ {u ∩ (x × y) | x,y
∈ u} ∪ {x ∩ {(a,b)2 | a ∈ b} | x ∈ u} ∪ {u ∩ {(b,a,c)3 | (a,b,c)3 ∈ x} | x ∈ u}
∪ {u ∩ {(b,c,a)3 | (a,b,c)3 ∈ x} | x ∈ u} ∪ {x"{w} | x,w ∈ u} ∪ {u ∩ {x"{w} |
w ∈ y} | x,y ∈ u}.

WS 2.75 (p. 22): "T is rudimentary, u ⊆ T(u) and u ∈ T(u). Further, if u is
transitive, then T(u) is a set of subsets of u, and hence T(u) is transitive."

WS 2.82 (p. 22), verbatim:

> For any transitive u, union_{n∈ω} T^n(u) is the rudimentary closure of u ∪
> {u}, and in it, TCo holds.

WS 2.83 PROBLEM (p. 23), verbatim:

> I do not see how to form a single rud function which will in similar fashion
> give the rud closure of u. Perhaps this has something to do with the question
> of MacAloon and Stanley discussed in §14.

MB 3.0-3.2 (p. 15) repeat the T definition and Proposition 3.2; MB 0.3 EXAMPLE
(p. 2):

> Jensen in [J2] gives a single rudimentary function that can be used to
> generate the constructible universe. We recall below the definition of a unary
> rudimentary function T, introduced in Weak Systems [M3], such that the
> following rudimentary recursion on On ... T0 = ∅; T(ν+1) = T(Tν); Tλ =
> union_{ν<λ} Tν ... generates L and the Jensen hierarchy in that L =
> union_{ν∈ON} Tν, and Jν = T_{ων}.

So Jν = T_{ων} (MB 0.3, p. 2; Fr slide 14: "L = union_{ν∈ON} Tν, and Jν =
T_{ων}; but ν -> ων is not rud rec").

Examples of the rud-closure limits (MB pp. 2-4):
- 0.13: "The function ζ -> 2·ζ is given by a rudimentary recursion. Nevertheless
  it is not rudimentary, for the rud closure of {ω} has ω as a member but, by
  Gandy [G], not EVEN = {2·n | n ∈ ω}."
- 0.14: "In Weak Systems [M3], §12, a transitive model of ZC is given in which
  TCo fails. Thus tcl though rud rec, cannot be rud."
- 0.16: "Corollary 14·5 of Weak Systems shows that J2 is not the rud closure of
  J1 ∪ {ω}, J1 not being a member of that latter set; but J2 is the rud rec
  closure of J1 ∪ {ω}; indeed of ω + 1."
- 0.18: "any rud function G only raises rank by a finite amount k, a uniform
  bound for all arguments; which we may call the rudimentary constant of G;
  from that it will follow that for a pure rud rec function F, for each argument
  x, ϱ(F(x)) < ϱ(x) + ω."
- 2.5 PROPOSITION (MB p. 13): "HF is not a member of the rud closure of {ω}."

WS 14.5 COROLLARY (p. 72) answers a McAloon question (WS 14.3-14.4):

> For any α > 0, Jα ∉ rud cl (Jα ∪ {ωα}).

WS 15.2 PROPOSITION (p. 75): "Neither ω̂ nor ω̄ is in rud cl({ω})" (Gandy
numerals).

MB 6.13 THEOREM (p. 26) is the rank-bound for rudimentary functions:

> Let R be a rudimentary function of n variables. There is a cR ∈ ω such that
> for every (cR + 1)-progress P0, P1, ..., PcR, R"P0^n ⊆ PcR.

with cRi = 1, 1, 1, 1, 3, 1, 5, 5, 2 for i = 0..8 (MB proof of 6.13, p. 26).
MB 6.14: cR is the "rudimentary constant".

## 3. Rudimentary recursion and provident sets

MB 6.0 DEFINITION (p. 26), verbatim:

> A set A is p-provident, where p is a set, if it is non-empty, transitive,
> closed under pairing and for all p-rud rec F (or equivalently all p-gentle F)
> and all x in A, F(x) ∈ A.

MB 6.4 DEFINITION: "A is provident if it is p-provident for every p ∈ A."
MB 6.5: "The only provident set not containing an infinite set is HF."
MB 6.6: for provident sets, closure under pairing is unnecessary (the function
y -> {x,y} is x-rud rec). MB 6.7: directed unions of provident sets are
provident. MB 6.8-6.10: indecomposable ordinals = ordinals of the form ω^α.
MB 6.9: "the rank of any provident set is an infinite indecomposable ordinal."

MB 6.35 THEOREM (p. 28), verbatim:

> Let <Pν | ν ≤ θ> a strict continuous (θ + 1)-progress. Then Pθ is provident
> iff θ is an infinite indecomposable ordinal.

MB 6.37: Pθ is ∅-provident iff θ is a limit ordinal. MB 6.57: Pθ is limit
provident iff θ has the form ω^α with α a limit ordinal.

MB p. 31 (The constructible hierarchy), verbatim:

> Since the Lν in the constructible hierarchy form a strict continuous progress,
> we know by Theorems 6.35, 6.37 and 6.57 that Lν is ∅-provident iff ν is a
> limit, provident iff ν is infinite and indecomposable, and limit provident iff
> ν is of the form ω^α with α a limit ordinal. We can say something similar
> about the Jensen hierarchy, since it is clear by induction that Jν = P^∅_{ω·ν}
> for any ν. Thus (since the function ν -> ω·ν is injective), Jν is
> ∅-provident iff ν > 0, provident iff ν is nonzero and indecomposable, and
> limit provident iff ν is of the form ω^α with α a limit ordinal.

MB 6.2 EXAMPLE: "the Jensen fragment Jν is ∅-provident for all ν ≥ 1."
MB 6.58: "by an induction argument, for any ordinal ν we have Jν(c) = T_{ω·ν}(c)"
and "Jν(c) is provident iff ν is nonzero and indecomposable with ω·ν > ϱ(c)".

Minimal model claim: the raw sweep attributes "minimal model J_omega" to MB.
That phrase is NOT in the fetched MB text. The fetched nearest statements:
Fr slide 28: "PROPOSITION Jω is provident. The next one will be Jω2." MB 5.9
REMARK (p. 26): "The first Jensen fragment after J1 that is closed under
functions of Type II is Jω". Marked: the sweep's "minimal model J_omega"
phrasing = not determinable from fetched text.

Theories PROV and PROVI (MB 7.3, p. 33): PROV = extensionality + the ten axioms
of GJ0 (the nine DB0 axioms plus (R8)) + "each set is in the domain of an
attempt at the rank function" + "any two ordinals are in the domain of an
attempt at ordinal addition" + "for each transitive c each ordinal is in the
domain of an attempt at the sequence <P^c_ν | ν ∈ ON>". "We write PROVI for PROV
+ ω ∈ V." MB 7.0-7.1: Prov(M), the provident closure of M, is the least
provident set including M, built as union over s ∈ S(M) of P^tcl(s)_θ with θ the
least indecomposable ordinal ≥ ϱ(M). MB 7.8 THEOREM (Bowler): finite closure
under the three functions Y1, Y2, Y3 characterizes ∅-providence (theory ∅-PROV,
p. 34).

Fr slide 32: "François Dorais has established the following 'reversals': Let HC
denote the statement that every set is countable. Then PROVI + HC is
bi-interpretable with ACA_0^+; and PROVI + HC + Mostowski Collapse is
bi-interpretable with ATR0."

## 4. The comprehension theorem (Q3)

The modern proof shape: transitive sets closed under the rud functions are
closed under Δ0 separation, by simulating each Δ0 formula by a rudimentary
function/term. The three versions below are the ones actually in the fetched
material.

### 4.1 Schindler-Zeman version (shortest)

SZ Lemma 1.4 (p. 8), verbatim:

> Let U be a transitive set, and let A be a set or proper class such that A ∩
> V^rk(U)+ω ⊆ U. Then P(U) ∩ rud_A(U ∪ {U}) = P(U) ∩ Σ_ω^{<U,∈,A>}.

Proof structure (SZ p. 8): the "⊇" direction reduces to P(U) ∩ Σ_ω =
P(U) ∩ Σ0 and uses Proposition 1.3 (f),(c),(h) (rud relations closed under
complement, intersection, bounded quantification) plus (a) and (d) (member-of
and membership in A are rud) to show every Σ0 relation is rud; then 1.3 (g)
gives x = U ∩ {y ; R(<y,x~>)} ∈ rud_A(U ∪ {U}). The "⊆" direction defines
"simple" functions (substitution of a function value into a Σ0 formula yields a
Σ0 formula over transitive rud_A-closed structures) and verifies inductively
that every rud_A function is simple; then "v0 ∈ f(<v1,...,vk>)" is Σ0 and x =
{y ∈ U ; y ∈ f(<x1,...,xn>)} is Σ0-definable. Total length: about one page
(SZ pp. 7-8).

Consequences:

SZ Lemma 1.5 (p. 8), verbatim:

> Let U be a transitive set such that for every x ∈ U there is some transitive
> y ∈ U with x ∈ y, let A be a set or a proper class, and suppose that U is rud_A
> closed. Then <U, ∈, A> is a model of Σ0 comprehension in the sense that if B ∈
> Σ_0^{<U,∈,A>} and x ∈ U is transitive then B ∩ x ∈ U.

SZ Lemma 1.8 (p. 10): for limit α, if B ∈ Σ_0^{J_α^A} then <J_α^A, B> is
amenable, i.e. J_α^A is a model of Σ0 comprehension in the language with Ȧ, Ḃ.

SZ also internalize satisfaction: 1.12-1.13 Propositions (pp. 12-13) define the
truth predicate Θ(f, N, n) for Σ0 formulae, giving "the relation |=_Σ0^M is
Δ^M_1" (1.13); 1.14 Theorem: the Σ1-satisfaction relation is uniformly Σ^M_1;
1.15 Theorem: J-structures have Σ^M_1-deﬁnable Σ1 Skolem functions. These
theorems (not Lemma 1.4) are what SZ's later fine structure uses.

### 4.2 Mathias-Bowler / Weak Systems version

MB 1.43 THEOREM (Bernays) (p. 11), verbatim:

> All instances of Δ0 separation are provable in the system DB0.

MB 2.1 PROPOSITION (p. 13), verbatim:

> (i) For each Δ0 class A the map x -> x ∩ A is in B.
> (ii) It is a theorem of MW that for each Δ̇0 wff φ the map a -> a ∩ {x | |= φ[x]}
> is in B.

MB 2.2 PROPOSITION: branching over Δ0 choices is coded by a rudimentary
function: x, y, z -> x if z ∈ A, y otherwise, with explicit expression
(p. 13). MB 2.13 THE GANDY-JENSEN LEMMA (p. 14), verbatim:

> Let S be a system extending DB0. Suppose that H is a 2-companion of F in S,
> and that 'a ∈ F(b)' is Δ^S_0. Then F is generated by composition from H and
> members of B, and so is S-suitable; if in addition S extends GJ, then ⊢S F"x
> ∈ V and F" (as a function) is generated by H and members of R and (as a term)
> is S-suitable and is a 1-companion of F in S.

MB 2.16 THEOREM: R is closed under formation of images and of unions of images.
MB 2.17 REMARK: "Gandy shows in [G] that these three are equivalent: (i) F is
rudimentary; (ii) 'a ∈ F(b)' is Δ0 and F has a 1-companion in GJ; (iii) 'a ∈
F(b)' is Δ0 and F has a 2-companion in GJ."

The truth-predicate version (MB section 9, pp. 37-38), verbatim:

> 9.0 THEOREM (Mathias) Truth for Δ̇0 sentences is uniformly Δ1 for transitive
> models of MW.

Proof structure (4 steps, MB pp. 37-38): Step 1 de-nest restricted quantifiers;
Step 2 put into prenex form with all quantifiers restricted by free terms;
Step 3 evaluate quantifier-free sentences in S_φ by a function g_φ : S_φ -> 2,
where the conjunction rules are "Δ0 in any sufficiently long attempt at
addition"; Step 4 reduce truth of φ* to substitution instances along the tree
T_φ of finite sequences, evaluated by a reverse induction. MB 9.2 THEOREM: "The
truth predicate |=u φ, for u a transitive set and φ an arbitrary sentence of
Lu, is Δ^MW_1." MB p. 37 cites the predecessor: "In [M3, section 10, culminating
in page 211] it is shown that the truth predicate |=u φ is, provably in MW,
Δ1-definable." MB 9.3 REMARK generalizes to small internal structures.

### 4.3 Welch draft version (extra source, secondary)

W section 3 gives the "simulation by terms" shape in full. W Theorem 2
(p. 7): "For any Δ0 φ in L_{Ȧ}, R ⊢ φ ⇐⇒ GJ ⊢ φ. Hence GJ is finitely
axiomatisable." The engine is W Lemma 7 (pp. 8-9): for any Δ0 φ there is a
rudimentary F with F(a, v0, ..., v_{k-1}, v_{k+1}, ..., vn) = {vk ∈ a ; φ(v0,
... vn)}, proved by induction on φ with clauses (i)-(xiv) (atomics, negation,
conjunction, variable permutation, substitution, bounded quantifier), about 1.5
pages. W Lemma 10: every Δ0 relation is rudimentary, with a recursive map k:
Fml0 × ω -> RudF producing the code. W also contains the Gandy-Jensen Lemma
(p. 6) and the finite basis list (Definition 5, p. 6: f0..f16+i, a 17+ function
list including A_i ∩ x for predicates). DRAFT: treat W statements as secondary
and check before relying on them.

### 4.4 Length and structure comparison (Q3)

- SZ: Lemma 1.4 is the whole theorem for one level; the proof is a single page
  (SZ p. 8) with two inductions (closure of rud relations under Σ0 operations;
  "simple" functions). No syntactic machinery (no code trees) is needed.
- MB: the same content appears as (i) the Bernays Δ0-separation theorem for
  DB0 (MB 1.43) and the separator/branching propositions 2.1-2.2; the heavy
  work is instead in section 9: truth for Δ0 sentences uniformly Δ1 over
  transitive models of MW, a 4-step proof of about 1.5 pages (MB pp. 37-38)
  resting on attempts at addition.
- W: the term-simulation route (Lemma 7) is spelled out with explicit code
  trees and a recursive map k; about 2 pages, and W Theorem 2 turns it into
  finite axiomatizability of GJ.

For the formalization route: SZ Lemma 1.4's "⊆" direction (simple functions)
is the part that needs care; MB section 9 shows the Δ0-truth predicate needs
addition attempts, hence the weak-system subtleties.

## 5. Rud relativization (Q5)

- SZ Definition 1.1 (p. 6): rud_A is the six-schema closure; the only schema
  involving A is f(x) = x ∩ A. So one added schema, not one added function,
  in SZ's presentation.
- SZ p. 7: "Membership in A is rud_A" (1.3(d)); P(U) ∩ rud_A(U ∪ {U}) = P(U) ∩
  Σ_ω^{<U,∈,A>} (1.4).
- SZ pp. 9-10: in the S-hierarchy basis, the A-schema becomes F15(x, y) = A ∩ x.
- WS 2.61 note (p. 19): the functions R0..R8 are for the unrelativized case;
  the predicates A_i appear in W's draft as f_{17+i}(x,y) = A_i ∩ x (W
  Definition 5, p. 6), i.e. one added function per predicate.
- The raw sweep asks "rud_A exactly (one added function? which?), per
  Zeman/Jensen": per the fetched SZ text the answer is: one added schema x ∩ A
  (Definition 1.1), equivalently F15 = A ∩ x in the finite basis (SZ p. 10).
  Zeman's own book (cite-only source 11) is not fetched; nothing in the fetched
  material contradicts the SZ presentation.
